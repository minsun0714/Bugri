# Landing editorial font

Hahmlet by The Hahmlet Project Authors, distributed under the adjacent SIL Open Font License. Source: https://github.com/google/fonts/tree/main/ofl/hahmlet (Hahmlet[wght].ttf).

`hahmlet-medium.woff2` is a static weight-500 instance with the complete source glyph coverage, converted using fontTools `instantiateVariableFont(font, {"wght": 500}, inplace=True)` then `font.flavor = "woff2"` and `font.save(...)`. No project runtime dependency or external font request is required. The 240,644-byte font is scoped to the guest landing headings through next/font/local.
