## PROFILE-PREVIEW — 데스크와 최신 퀴즈 미리보기

- 상태: IN_PROGRESS. 사용자 정보 → 작은 데스크(크게 보기/접기) → 최신 공개 퀴즈 최대 4개(전체 보기) → 학습 활동으로 구성. 프로필 검색·필터·페이지 이동은 제거하고 기존 전체 목록에서 유지한다. 최근 공개 시각을 기록하며 내용 수정만으로 순서를 올리지 않는다. 공개 시각 없는 기존 저장 데이터는 임의 추정하지 않고 알려진 시각 뒤에 안정적으로 정렬한다.
- 상태: DONE. 후속 사용자 요청을 반영해 데스크는 축소 없이 큰 캔버스(모바일 320px/데스크톱 420px)로 제공한다. 데스크 제목·크게 보기/접기·편집 링크·기본 데스크 안내와 45도 시점/정면/위에서 버튼을 제거하고 드래그 시점 조작은 유지한다. 편집은 마이페이지에서 진입한다.
- 프로필은 페이지/태그 URL과 무관하게 최근 공개 퀴즈 4개를 요청하고 데스크톱 2열·모바일 1열로 표시한다. 전체 보기는 기존 개발자 퀴즈 목록에 사용자 쿼리를 보존해 연결한다. 검색/태그/페이지 이동은 전체 목록에 유지한다.
- 공개 시각은 직접 공개·최초 PUBLIC 승인·PRIVATE→PUBLIC에 기록한다. PUBLIC 수정본 승인/동일 공개 상태는 시각을 유지한다. 시각 없는 기존 v1 저장은 유지하며 알려진 시각 뒤에 정렬한다. API 정상/수정/재공개 정렬과 6개 중 최신4개 반환을 테스트했다.
- Node v22.23.3 최종 `npm run verify` 전체 통과: lint·TypeScript·Jest 39 suites/188 tests·도구 테스트3개·production build·Chromium E2E117개. 최초 lint 포맷 오류 수정. 중간 축소 화면 검증의 시점 버튼 테스트 실패는 최종 요구에 맞게 드래그로 정면을 만드는 검증으로 변경했으며, 중간 픽셀 가시성 검사 실패도 최종 전체 실행에서 통과했다. 검사를 생략하지 않았다.
