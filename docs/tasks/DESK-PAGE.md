## DESK-PAGE — 데스크 편집 전용 페이지

- 상태: IN_PROGRESS. 사용자 승인에 따라 `/my`에서 데스크·보유 상품을 `/my/desk`로 이동한다. 공개 프로필은 조회 화면을 유지하고 본인 데모 로그인 시 편집 진입을 제공한다. REQ-09의 페이지 경로와 관련 문서·테스트를 함께 갱신한다.
- 구현 완료, 전체 검증 대기(IN_PROGRESS 유지). `/my/desk`에 기존 편집기를 그대로 이동하고 마이페이지에는 개인 컨테이너·편집 링크만 남겼다. 브레드크럼·편집기 데모 사용자 전환·레거시 `/shop/zdog` 리다이렉트·데스크 E2E 진입 경로를 갱신했다.
- Node v22.23.3. 관련 Jest 11개 통과. 마지막 `npm run verify`: lint·TypeScript 통과, Jest 182 통과/기존 헤더 기대값 불일치 2 실패. 이후 전체 pipeline 단계는 실행되지 않았다. 별도 production build 및 profile-split/my-desk/shop E2E 8개 통과. 나머지 데스크 E2E는 경로만 갱신했으며 이번에 전체 재실행하지 않았다.
- 초기 E2E에서 남아 있던 `/my` URL 기대값을 새 경로로 수정했다. 마이페이지 캡처는 Suspense 로딩 완료를 기다리도록 보완했다. 개인 페이지에 캔버스가 없는지, 편집 진입·본인 공개 프로필 편집 링크·구매/장착·사용자 전환·레거시 진입을 검증했다.
- 독립 UX 리뷰: UI 수정 0회, 최신 데스크톱·390px 모바일 캡처/코드/E2E 로그 검토에서 필수 미해결 사항 없음. 독립 키보드 조작·오류 상태 검증은 미실행.
