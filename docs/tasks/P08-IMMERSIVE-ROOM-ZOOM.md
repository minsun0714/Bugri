- 상태: IN_PROGRESS. REQ-09/AC-09e. 최소 배율에서 유한한 배경 외곽이 드러나는 현상을 PC/모바일 E2E로 재현했다. 화면 전체 방 바탕과 현재 뷰포트/배율을 넘는 벽·바닥 범위를 사용하고 반대쪽 벽도 제공해 회전·축소 시 방 내부 느낌을 유지한다. 두 테마의 최소 배율·좌우 한 바퀴·상하 시점에서 빈 픽셀 없는 화면을 검증한다.
