### A 미확정 수정 중 탭 이동 — DONE

- 직접 수정 초안을 퀴즈별로 보관하고 미리보기·LLM 수정·다른 퀴즈 탭 이동을 허용한다. 다른 초안이 남아 있으면 일괄 저장과 이탈 경고를 유지한다.
