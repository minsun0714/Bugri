## PROFILE-PRIORITY — 공개 프로필의 퀴즈 중심 구성

- 상태: IN_PROGRESS. 사용자 이름·구독 진입과 공개 퀴즈 목록/태그 필터를 상단으로 옮기고 학습 활동·데스크를 하단에 배치한다. 기존 DeveloperScreen을 재사용하며 공개 프로필의 태그 선택은 필터만 수행한다. 비로그인 구독 클릭은 데모 로그인으로 연결하고 구독 변경은 로그인 후 명시적으로 수행한다. 실제 소개/활동 데이터·프로필 편집 기능은 추가하지 않는다.
- 상태: DONE. 사용자 이름·공개 ID를 제목 영역으로 제공하고 본인은 프로필 편집 진입, 방문자는 로그인/구독/해제를 제공한다. 빈 프로필 상자는 제거했다. 공개 퀴즈 목록을 직접 표시하고 URL에 태그·페이지·데모 사용자를 유지한다. 미구현 자기소개나 학습 활동 데이터는 생성하지 않았다.
- Node v22.23.3 최종 `npm run verify` 전체 통과: lint·TypeScript·Jest 39 suites/186 tests·포트 도구 테스트 3개·production build·Chromium E2E 116개. 신규 테스트로 정보 순서, 직접 풀이 진입, 태그 필터만으로 구독이 바뀌지 않음, 데모 로그인만으로 구독하지 않음을 검증했다. 최초 타입 검사에서 테스트 옵션 오류를 수정했고, E2E의 풀이 진입 URL 기대를 실제 Attempt 시작 후 URL로 바로잡았다.
- 독립 UX 리뷰: 최신 데스크톱·390px 모바일 실제 캡처/코드/실행 결과 검토, 필수 수정 사항 없음(수정 0회). 모바일 첫 화면에 공개 퀴즈가 보이며 데스크가 아래에 배치됨을 확인했다. 독립 브라우저 조작·오류 상태 재현은 미실행. 최종 UI 변경 이후 전체 검증과 diff check를 통과했다.
