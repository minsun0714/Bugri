## PAGE-SHELLS — 미구현 마이페이지 영역 컨테이너

- 상태: DONE(요청한 자리 표시자 범위). 병합된 Shop·데스크·보관함·퀴즈 작성/풀이·탐색은 재구현하지 않고 기존 화면을 유지한다.
- `/my`에 내 프로필, 학습 기록·스트릭, BugCoin 내역, 학습 시간대 설정을, 홈에 로그인 사용자용 스트릭 요약과 탐색에 로그인 사용자용 내 구독 영역을 제목과 빈 컨테이너로 추가한다. 비로그인 랜덤 체험은 기존 `오늘의 퀴즈`와 중복되는 빈 상자로 노출하지 않고 동작 구현 시 별도로 통합한다. 이 자리 표시자는 기능 구현 완료 근거가 아니며 API·가짜 데이터·동작을 포함하지 않는다.
- 구현 범위: 기존 페이지에 미구현 UI 영역 추가. 관련 제품 기준은 PRD REQ-02·05·09·12·13의 남은 사용자 화면이다. 수정 파일 ESLint와 `git diff --check` 통과. 상위 지침에 따라 테스트는 실행하지 않았다. UX sub-agent의 정적 문서·코드 검토에서 필수 수정 사항은 없었고, 브라우저 캡처/상호작용 리뷰는 미실행이다.
