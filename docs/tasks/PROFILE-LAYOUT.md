- 상태: DONE(최신 사용자 요청 구현·검증 범위). 사용자 승인: 앞선 두 차례 UI/UX 지적 전체 개선. REQ-14 범위에서 이름·ID·소개·링크를 묶고, 편집 동작을 동일한 보조 스타일로 상단 배치하며 모바일에서는 콘텐츠 뒤에 둔다. 본문 16px, 제한된 정보 폭, 서비스별 링크 아이콘·외부 이동 표시와 기타 링크 목적지를 제공한다. 저장 데이터의 사용자 지정 이름은 임의로 고치지 않는다.
- 검증: 기존 편집/저장/취소/사용자별 노출 E2E와 신규 PC·모바일 정보 배치 검사, 독립 UX 리뷰, 최종 전체 verify.

- 구현: ProfileAbout에서 identity·소개·링크·관리 동작을 함께 조립하고 본문16px/28px, 상단최대896px, 관리동작 그림자/테두리 제거, 링크 종류별 아이콘/외부화살표/기타 도메인을 적용했다. 기타 지정 이름과 기존 저장/API 계약은 유지한다.
- 관련 검증: 신규 배치 E2E의 미구현 실패 확인 후 구현. 기존 편집/삭제/저장/취소/프로필 분리 E2E 통과. shadow-none의 브라우저 계산값이 투명한 0px 그림자 목록이어서 명시적 box-shadow:none으로 정리 후 새 배치 2개 통과. 독립 리뷰 후 긴 이름·도메인/접근성 검사를 추가하여 관련 E2E5개 최종 통과. 관련 Jest3개·TypeScript·lint 통과.
- [독립 UX 리뷰](../ux-reviews/PROFILE-LAYOUT.md): 새 컨텍스트 R0에서 일반문제1건(긴 기타명 뒤 도메인 분절·보조기술 누락), C1/R1에서 도메인 묶음 줄바꿈·접근성 이름 보완 후 직접 PC/모바일 재검증 완료. 수정1회, 필수 미해결 없음. 최종 전체 verify 진행 중.
