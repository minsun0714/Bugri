# HOME-QUIZ-01 오늘의 퀴즈 리뷰 개선

## 범위와 근거

- 사용자 목표: 방문자는 홈에서 일시적인 랜덤 공개 퀴즈를 체험하고, 명시적으로 선택한 데모 사용자는 구독 기반 문제를 풀고 다음 문제·재도전을 이어간다.
- 관련 요구: PRD AC-05b~h, REQ-12, AC-13a. 실제 인증·AI·지급 정책 변경 없음.
- 사용자 후속 지시로 **연속 학습·학습 기록·달력은 제외**했다. 작업 중 추가했던 관련 컴포넌트·경로·API는 제거했고 `home-sections.tsx`의 기존 자리 표시자를 원복했다. 빈 영역과 그에 따른 밀림은 별도 브랜치 작업이며 이번에 해결했다고 주장하지 않는다.
- Node v22.23.3, 현재 워크트리 미커밋 소스. 동일 워크트리 `http://localhost:3000`에서 Playwright Chromium 직접 조작·캡처 확인.
- 최초 리뷰 R0: 독립 UX/UI 각 1명. 수정 후 R1: 새 컨텍스트의 독립 UX/UI 각 1명. R0는 서버 준비 중 코드부터 읽은 한계가 있다. R1은 실제 화면을 먼저 확인했다.

## 회차와 한계

- R0 → C1 구현 → R1 독립 재검토 → C2 닫힌 모달 입력 중복 제거 → R2 → C3 취소 포커스 복귀 → R3. 공통 수정 3회. R1에서 범위 내 필수 수정 문제 0개였고, 후속 E2E 및 R2에서 아래 회귀를 발견해 수정했다.
- UX 확인: 1440×1000, 390×844. UI 확인: 1440, 375×667, 390×844. 메인 E2E는 추가로 375px 다음·재도전 초점과 문제 가시 영역을 검증했다.
- R1 UX 증거: `/tmp/ux-home.png`, `/tmp/ux-review-result.png`, `/tmp/ux-review-switch.png`, `/tmp/ux-review-demo.png`.
- R1 UI 증거: `/tmp/ui-review-home1440.png`, `/tmp/ui-review-375.png`, `/tmp/ui-review-result390.png`, `/tmp/ui-review-demo390.png`, `/tmp/ui-review-member1440.png`, `/tmp/ui-review-member375.png`.
- 리뷰어 미확인: 긴 코드, 전체 키보드·스크린리더, 오류·빈 상태·소진의 실제 화면. 이 범위의 UI 통과를 주장하지 않는다. 자동 회귀 테스트의 관련 결과는 TASKS 검증 기록에 별도 기재한다.
- 독립 UX는 방문자 API의 읽기 전용 반환·공개/삭제/revision 재검사를 코드로도 확인했다. 프로토타입 저장소의 보안 보장을 의미하지 않는다.

## 최종 자동 검증

마지막 코드 변경 후 Node v22.23.3에서 `PLAYWRIGHT_PORT=3195 npm run verify` 전체 통과: lint·TypeScript·Jest 43 suites/202 tests·도구 테스트 3개·production build·Playwright 126 tests. 관련 회귀에는 방문자 저장 없음·데모 전환, 375px 다음/재도전 포커스, 모달 취소 트리거 복귀, 네 문제 형식·태그·소진·저장 실패 입력 보존·비공개 완료 성과 유지가 포함된다. 자동 검사 통과는 위에 기록한 최초 로딩 포커스 경합을 해결했다는 뜻이 아니다.
