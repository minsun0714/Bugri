# PROFILE-STREAK — 공개 프로필 학습 활동

## 대상과 확정 범위

- 사용자 목표(검토용 가설): 공개 프로필 주인의 학습 꾸준함과 기간별 완료량 확인.
- 사용자 요청: 빈 학습 활동 영역에 홈 스트릭 그대로 표시. 홈 StreakSummary/ActivityPeriods를 재사용하며 공개 프로필에서는 주인에 대한 사실 문구를 사용한다.
- 공개 집계는 프로필 publicId 기준. 개별 문제/답안/정오/잔액은 반환하지 않는다. 시간대 미설정은 기존 오류·재시도로 표시하고 임의 시간대를 정하지 않는다.
- HEAD b8871d8 위 변경. Node v22.23.3. API와 Mock 집계, public-desk 및 streak 컴포넌트 변경. ShopProvider 내부 API 훅 사용.

- `/tmp/profile-streak-review/activity-1280-guest.png`, `activity-390-guest.png`, 같은 디렉터리의 본인/타인 및 `activity-error-1280.png`/`activity-error-390.png`.
- 메인 직접 자동 조작: 2일연속·오늘완료·월총2개·오늘1개, 월→년→월과 제목초점복귀, 가로overflow없음, friend프로필전환후 시간대오류·재시도·기존기록제거.
