# P08-COIN-DEMO UX 리뷰

## 대상과 증거

- 검토용 사용자 가설: 마이페이지에서 BugCoin 더미 내역과 페이지네이션을 직접 확인하려는 프로젝트 사용자. 기존 잔액/구매 보존, 지급 정책 미결정, Mock만 사용한다. 다른 마이페이지 자리표시자는 제외한다.
- HEAD 764000f + 이번 미커밋 변경. `/my?user=learner`, 전용 서버 3149. 새 컨텍스트 독립 리뷰어가 Chromium PC1280×900·모바일390×844에서 직접 조작했다.
- 캡처 `/tmp/bugri-coin-demo.png`, `/tmp/coin-review-desktop.png`, `/tmp/coin-review-mobile.png`.

## 최초 관찰과 흐름

개인 관리 화면에서 BugCoin 내역→잔액→날짜별 지급→이전/다음 순서로 읽었다. 잔액100·25건을 10/10/5로 확인하고 1→2→3→키보드 Enter로 이전 페이지 복귀를 수행했다. 모바일 상점 구매 후 재진입하여 잔액70·최신 상품 구매-30·데모 지급 유지까지 직접 확인했다.

## 관점별 평가

| 관점                  | 판단                | 관찰 근거                                                               |
| --------------------- | ------------------- | ----------------------------------------------------------------------- |
| 목적/대상 식별        | 문제 없음           | 내 잔액·데모 지급 문구로 본인 내역과 예시 성격 구분                     |
| 정보 우선순위·첫 화면 | 기존 배치 제약      | 영역 안에서 잔액이 우선. 앞선 자리표시자로 스크롤 필요하나 이번 범위 밖 |
| 핵심 행동·이동 단계   | 문제 없음           | 하단 현재/전체 페이지·이전/다음으로 3페이지 탐색 및 복귀                |
| 불필요한 요소·밀도    | 문제 없음           | 날짜·금액 분리, 예시 지급 반복과 불필요한 설명 없음                     |
| 상태·피드백           | 확인 범위 문제 없음 | 구매 후100→70·-30 일치, 첫/마지막 경계 버튼 비활성                      |
| 모바일·키보드         | 확인 범위 문제 없음 | 390px 잘림/수평 넘침 없음, 버튼 이름과 Enter 이동                       |
| 방문자·본인·타인      | 일부 미확인         | URL learner 더미 사용자 본인만 직접 확인. 실제 인증/타인 통제 검증 아님 |

## 문제 목록과 처리

필수 수정 문제 0개. 앞선 자리표시자 배치는 이번 데이터 추가와 독립된 기존 설계이므로 변경하지 않는다. 원본 seed의 다섯 조건 일치 시에만 치환하는 구조는 코드로 검토했다.

## 회차와 종료

| 회차 | 변경               | 근거·결과                                                      | 한계                                                                                                                  |
| ---- | ------------------ | -------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| R0   | 최초 리뷰, 수정0회 | PC/모바일 예시 탐색·키보드·구매/차감 직접 확인, 필수 문제 없음 | 로딩·빈·오류재시도·스크린리더 음성·전체 키보드 순회 미확인. 기존 데이터 변환은 리뷰어 코드 검토 및 구현자 단위 테스트 |

핵심 요청인 기본 예시 표시·페이지 이동·구매 내역 보존을 확인해 조기 종료한다. 전체 앱 UX 완료를 뜻하지 않는다.
