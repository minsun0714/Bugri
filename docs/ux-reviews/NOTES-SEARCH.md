# NOTES-SEARCH UX·UI 리뷰

[NOTES-SEARCH](../tasks/NOTES-SEARCH.md)의 `/notes` 검색·태그 필터를 대상으로 한 [ux-review-loop](../../.agents/skills/ux-review-loop/SKILL.md) 기록이다. 독립 UX 리뷰어 1명·UI 리뷰어 1명을 새 컨텍스트로 실행했고 수정 후 같은 리뷰어를 재사용했다. 실제 수정은 C1·C2 두 번, 재검증은 UX R1·R2, UI R1이다(UI는 C2 변경이 UX 영역이라 R2를 생략했고, C2에서 UI-13을 함께 해소했다).

## 대상과 증거

- 사용자 가설(검토용): 업무 중 적어 둔 메모를 "그때 적은 그거"로 찾으려는 현업 개발자(데모 사용자 learner). 성공 행동: 검색어·태그로 메모를 찾아 상세로 이동, 뒤로 가면 조건 유지.
- 확정 제약: PRD AC-01e·h·i·j, 페이지 구조 "내 노트". 구현 선택(칩 모양, 문구, 일치 표시)은 변경 가능.
- 증거: 이 워크트리 dev 서버(격리 포트 3217)를 Playwright MCP로 직접 조작. 데스크톱 1280×800, 모바일 360(·320 일부), 라이트·다크, 한국어·영어 일부.
- 한계: Playwright 브라우저가 다른 세션과 공유되어 URL·언어가 임의로 바뀐 순간이 있었고 해당 측정은 재측정했다. 영어·라이트 전체 재점검, 실제 스크린리더 낭독, 칩 많은 상태, 페이지네이션 상태는 리뷰어가 확인하지 못했다.

## 리뷰 이후 추가 변경 (독립 리뷰 미실시)

R2 종료 뒤 사용자 결정으로 "확인 안 한 퀴즈 있음" 칩(태그 칩 아래 별도 줄), 검색 결과 행의 "확인 안 함" 뱃지, PENDING 퀴즈 검색을 추가했다. 이 변경은 독립 UX·UI 리뷰를 받지 않았고 단위·E2E 테스트(칩 필터, 뱃지, URL 복원)만 확인했다. 데스크톱·모바일·다크·영어에서의 시각 확인은 미실시다.
