# STREAK-HOME-UX — 홈 요약·접힘 달력 후속 리뷰

## 대상과 증거

- 2026-11-08 후속 작업. 데모 학습자가 홈에서 기록을 짧게 확인하고 바로 문제를 읽고 푸는 것이 목표다.
- 확정 요구: 홈 요약·오른쪽 달력 버튼, 기본 접힘, 모바일 오늘 상태 두 줄 허용, 제출 후 펼침 유지, 공개 프로필 유지.
- 버전: 이번 커밋의 home-streak.tsx/streak-summary.tsx. 앱 코드는 최초 캡처부터 리뷰 종료까지 동일하다.
- 캡처: `.bugri-hooks/previews/streak-compact/`. 초기 1280×844·390×844·320×568, 펼침 390×844(fullPage), 재시작 390×844, 공개 프로필 1280/390. 추가 `incomplete-320.png`, `completed-top-{320,390,1280}.png`는 어제 학습 후 오늘 제출한 상태다.
- 구현자가 Playwright로 직접 조작·촬영했다. 독립 UX 및 UI 리뷰어는 각각 새 컨텍스트에서 view_image로 화면을 먼저 보고 코드·제공 조작 증거를 확인했다. 리뷰어 직접 브라우저 조작은 하지 않았다.
- `compact-completed.png`는 결과 카드까지 스크롤된 상태여서 접힌 요약의 증거에서 제외하고 `completed-top-*`로 보완했다.

## 최초 관찰과 흐름

UX: 작은 학습 상태 아래 오늘의 퀴즈에서 바로 답을 선택하는 화면으로 이해된다. 달력은 보조 행동이다. 진입→답 선택→제출→오늘 완료 갱신·접힘 유지→Enter 펼침→Space 접힘을 제공 조작 증거로 확인했다.

UI: 약66px 요약 행보다 퀴즈 제목·문제 문장이 강하게 보여 다음 행동을 읽기 쉽다. 320px 상태 두 줄에서도 캐릭터·달력 버튼이 충돌하지 않는다.

## 문제 목록과 처리

독립 UX·UI 리뷰 모두 필수·일반·선택적 문제 0개. 캡처 누락은 R0 증거를 추가해 해소했으며 앱 수정은 필요하지 않았다.

독립 UX 리뷰어의 코드 리뷰: 홈 전용 분기, 공개 프로필 유지, 동일 사용자 갱신 시 펼침 유지, userId key 초기화, 닫힌 달력의 탐색 요소 제거, API·집계 미변경을 확인했으며 구체적 회귀를 발견하지 않았다.
