## 범위와 증거

사용자 승인: 자기소개 Markdown만 얇은 테두리·안쪽 여백으로 묶고 제목·그림자를 추가하지 않는다. 외부 링크는 아래에 별도 표시한다. 후속 사용자 요청으로 최대768px 제한을 제거하고 헤더 콘텐츠 좌우 끝과 일치시킨다. 소개가 없으면 빈 컨테이너도 없다. 데스크는 변경하지 않는다.
