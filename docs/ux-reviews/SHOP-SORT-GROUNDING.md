# SHOP-SORT-GROUNDING

## 대상·원인·설계

- 상품 정렬을 공통 Dropdown으로 교체하고 달빛 작업실 장착 미리보기의 떠 보이는 책상 접지를 보완한다. 상품 정책·책상 높이·다리 길이·카메라 설계는 유지한다.
- 다리 하단과 러그는 모두 y=0이다. 실제 높이 틈이 아니라 접점 명암 부재가 부유감을 유발하는 것으로 판단했다. 방 원근/가구 직교 투영 차이도 인지에 영향을 줄 수 있으나 이번에 투영을 재설계하지 않는다.
- UI 사전 설계에 따라 각 다리 아래 작은 단계별 투명 그림자를 러그 위·가구 아래에 그린다. 기존 책상과 추가 미리보기 책상의 이동·회전을 따르되 바닥 y=0에 유지하고 아래쪽에서는 뒷면을 표시하지 않는다. 선택용 색상 맵에서 그림자는 상품 소유자가 없는 배경이다.
- 사용자 가설: 상품을 정렬하고 장착 모습을 확인한 뒤 구매하려는 데모 학습자.
