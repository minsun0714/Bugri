# P08-MY-ACTION R0 UX·UI 리뷰

## 대상·증거

검토용 사용자 가설: 마이페이지에서 데스크 편집에 진입하려는 사용자. 확정은 제목 우측 보조 버튼과 공간 부족 시 줄바꿈. 범위는 해당 링크·제목, 다른 기능/데이터는 제외한다. HEADe33e707 + page.tsx diff. 각 역할 별 새 컨텍스트 리뷰어가 화면을 먼저 관찰한 뒤 코드를 확인했다. 전용3155 `/my?user=author`, 독립 Chromium1280/390/320에서 직접 조작.

## UX 관찰

| 관점 | 판단·근거 |
| --- | --- |
| 목적·대상 | 마이페이지와 명확한 행동명으로 개인 관리/편집 진입 구분 |
| 첫 화면·우선순위 | 제목/액션이 상단에 보이고 BugCoin과 분리 |
| 행동·이동 | 클릭·Tab/Enter로 /my/desk?user=author 이동, 중간 단계 없음 |
| 중복·밀도 | 하나의 액션, 설명 중복 없음 |
| 상태 | 3px 보라 focus outline 및 정상 이동 |
| 모바일·키보드 | 390같은줄,320다음줄우측. 높이47.5px, 넘침 없음 |
| 사용자 상태 | author 쿼리와 데모 로그인 전후 직접 이동. 타인 제외 |

## UI 관찰

제목과13px 보조버튼의 위계, 흰색secondary와 본문primary 구분, 제목/버튼 수직중앙 정렬 및 카드 우측 일치, 카드와24px 간격을 직접 확인했다. 공통 테두리·배경·그림자를 사용하고390px 잘림 없이320px 줄바꿈이 된다. 키보드포커스와 Enter이동도 확인했다.

## 문제·처리·회차

UX/UI 모두 필수/일반 문제0개. R0 수정0회로 종료한다. 확정 배치를 변경하거나 추가 구현하지 않았다.
