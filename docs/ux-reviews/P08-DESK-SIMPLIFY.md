# P08-DESK-SIMPLIFY 리뷰

## 대상과 증거

- 사용자 목표: 본인 `/my/desk`에서 데스크를 편집하고 공개 프로필로 돌아간다. 이웃 영역·메뉴와 시점 프리셋 제거는 사용자 확정 요청이다.
- R0: 9a7d573 기반 미커밋 구현. `/tmp/bugri-desk-review/desk-1440.png`, `desk-390.png`: 1440×900, 390×900 전체 페이지, learner 빈 보관함. 독립 UX/UI 리뷰어가 각각 캡처를 직접 확인했다.
- 구현자 브라우저 조작: 두 크기에서 Canvas 표시, 이웃/프리셋 부재, 내 공개 프로필 보기 → `/users/bugri-learner` 이동 확인. 리뷰어 독립 조작은 수행하지 않았다.

## UX R0

| 관점             | 판단과 관찰 근거                                                                               |
| ---------------- | ---------------------------------------------------------------------------------------------- |
| 목적/대상        | 내 데스크 제목·학습자 표시·내 공개 프로필 링크로 본인 편집 화면을 식별한다.                    |
| 우선순위/첫 화면 | 캔버스와 프로필 복귀 링크가 두 화면 첫 viewport에 있다.                                        |
| 핵심 행동/이동   | 공개 프로필 복귀는 구현자 조작 증거로 확인. 빈 보관함 캡처로 장착·저장 완료는 확인하지 않았다. |
| 밀도/중복        | 이웃 영역과 시점 버튼이 없고 빈 버튼 행도 남지 않았다.                                         |
| 상태/피드백      | 빈 보관함 안내와 상점 이동을 확인. 저장·오류 화면은 미확인이다.                                |
| 모바일/접근성    | 390px 링크·선택 버튼·카테고리가 화면 안에 배치된다. 키보드·스크린리더 실조작은 미확인이다.     |
| 본인/타인        | 본인 learner 캡처만 확인. 타인 프로필 경로 자체는 코드상 유지된다.                             |

독립 코드 리뷰: 엔진·선택·이동·저장 콜백은 유지되며 `showViewPresets`만 숨긴다. users 조회는 본인 공개 프로필 링크에도 필요하므로 유지가 맞다. 변경 범위 회귀 발견 없음.

## 문제와 회차

두 역할 모두 요청 범위 필수/일반 문제 0개. 취향 개선을 추가하지 않았다.

| 회차 | 처리                    | 미확인                                                          |
| ---- | ----------------------- | --------------------------------------------------------------- |
| R0   | 추가 UI 수정 0회로 종료 | 독립 드래그·키보드·저장/오류 조작, 스크린리더, 게스트/타인 화면 |

구현자의 관련 E2E는 드래그·장착·회전·저장·재조회·공개 프로필 복원을 별도 검증한다. 독립 시각 리뷰와 동작 테스트 근거를 구분한다.

## 최신 dev 통합 후 재검토

- 사용자 후속 요청으로 origin/dev `76d1dcd` 통합. TASKS·shop 테스트 충돌은 양쪽 추가 내용을 보존했다. 독립 코드 리뷰가 삭제 없는 기록 보존과 dev Dropdown·embedded 사용자 전환 로직 보존을 확인했다.
- `/tmp/bugri-desk-review/integrated-1440.png`, `integrated-390.png`는 통합 후 동일 크기 전체페이지 캡처다. 통합 전 R0 캡처로 대체하지 않았다.
- 두 독립 리뷰어가 최신 캡처를 확인해 이웃/프리셋 재등장 없음, 빈 버튼 행 없음, 본인 데스크·프로필 복귀·모바일 필터 줄바꿈 유지 확인. 추가 UI 수정 0회, 필수 문제 없음.
- 구현자가 두 크기에서 Canvas 표시·제거 대상 부재·프로필 복귀를 직접 재확인했다. 리뷰어의 독립 드래그·키보드·저장/오류 조작은 미확인으로 유지한다.
