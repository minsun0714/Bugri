## 대상·증거

검토용 가설: 마이페이지에서 잔액과 지급/사용 내역을 빠르게 읽으려는 사용자. 사용자 승인 범위는 시각적 위계·너비·카드/여백 정리와 페이지당5개이다. 필터/잔액/데이터 정책은 유지한다. HEAD07d53ed+해당 UI diff, 전용3151 `/my?user=learner`를 새 컨텍스트 독립 리뷰어가 화면 먼저 보고 코드를 확인했다. Chromium 격리 context, PC1280×900·모바일390×844 직접 조작.

캡처: `/tmp/bugri-coin-refined-desktop.png`, `/tmp/bugri-coin-refined-mobile.png`, `/tmp/bugri-coin-refined-mobile-debit.png`.

## 최초 관찰·흐름

개인 관리 화면에서 큰 잔액을 읽고 필터로 거래 종류를 선택하는 다음 행동이 명확했다. 진입→잔액→다음2/5→사용빈→지급복귀1/5→방향키 필터를 직접 수행했다. 별도 세션에서 상점 구매→사용필터→잔액70/-30도 확인했다.

| 관점 | 판단 | 근거 |
| --- | --- | --- |
| 목적/대상 식별 | 문제 없음 | 마이페이지·BugCoin 내역·내 잔액 명칭 |
| 정보 위계·첫 화면 | 문제 없음 | 36px 잔액, 사유/날짜/금액 구별, PC768px 너비. 모바일 잔액·필터·5행 노출 |
| 핵심 행동·이동 | 문제 없음 | 다음2/5, 사용→지급1/5 초기화 직접 확인 |
| 중복·밀도 | 문제 없음 | 단일 카드, 하단 placeholder를 선/제목으로 축약 |
| 상태·피드백 | 확인 범위 문제 없음 | 사용빈·구매후70/-30·필터선택, 단일페이지에서 이동기 숨김 |
| 모바일·키보드 | 확인 범위 문제 없음 | 390px 잘림 없음, 방향키 필터/3px focus outline, 버튼 접근성 이름 |
| 방문자·본인·타인 | 일부 미확인 | learner 직접 확인. 실제 권한은 범위 밖 |
