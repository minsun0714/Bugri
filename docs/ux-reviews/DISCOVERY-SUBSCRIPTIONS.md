## 최초 관찰과 흐름

- UX: 구독 목록을 찾고 관리하는 화면으로 이해. 내구독→전체보기→검색/필터→해제→개수·초점 갱신, Escape와 목적지 이동을 직접 확인.
- UI: 제목→검색→유형→개수→목록→페이지이동 순서. 배경 탐색 페이지의 흰색·보라색·연두색 및 둥근 형태를 유지한다.

## 문제와 회차

- R0: 두 독립 리뷰 모두 필수 수정 문제0개. 수정회차0회로 종료. 문제 없는 판단은 위 실제 관찰에 한정한다.
- 메인이 구현 중 마지막 구독 해제 후 사라지는 전체보기 버튼 대신 summary로 초점 복귀하는 fallback을 추가했다. 사용자 요청 검색placeholder는 ‘이름 또는 아이디로 검색’으로 바꿨다. 리뷰어 발견 문제로 기록하지 않는다.
