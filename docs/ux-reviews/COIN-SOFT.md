# COIN-SOFT — 홈과 맞춘 작은 시각 조정

## 대상과 증거

- 요청: 코인 내역을 홈과 맞추되 아주 살짝 귀엽게. 본인 잔액·지급/사용 내역 조회 목적, 기존 배치·기능 유지.
- 기준: a62e6c6 위 `src/components/coins/coin-history.tsx` 스타일 변경. 별도 UI 설계 sub-agent가 홈의 rounded-3xl 카드·rounded-xl 컨트롤·연보라 선택 표시와 기존 작은 Coin 아이콘 재사용을 제안했다.
- 구현: 카드/탭 모서리, 연보라 선택색, 작은 금색 코인 표시와 미세 기울기만 변경. 설명문·기능·공통 컴포넌트 수정 없음.
- 증거: `/tmp/bugri-coin-soft/{coins,debit,home}-{1280,390}.png`. 전체 페이지 캡처, viewport 1280×900·390×900, learner. 격리된 production 서버 3217에서 캡처했다.
- 메인 Playwright 조작: 사용 탭 클릭 → 선택 상태 확인 → 전체 탭 키보드 Enter 복귀 → 5행 및 가로 넘침 없음, 두 너비 모두 성공.

## 독립 R0

UX/UI는 각각 새 컨텍스트에서 캡처를 먼저 확인하고 diff를 검토했다. 브라우저 직접 조작은 메인이 수행했으며 리뷰어는 제공 증거로 간접 확인했다.

| 관점 | UX 관찰 | UI 관찰 |
| --- | --- | --- |
| 목적·위계 | 본인 잔액과 내역 조회 목적이 명확하고 첫 화면에 잔액·필터 표시 | 제목→잔액→필터→목록의 위계 유지 |
| 핵심 행동·상태 | 필터→빈 상태→전체 복귀에 추가 경유 없음 | 선택 탭의 연보라 면·진한 보라 글씨가 비선택과 구분 |
| 밀도·일관성 | 추가 설명문·컨트롤 없이 5행 유지 | 홈과 같은 흰 면·연보라 경계·둥근 카드, 22px 코인이 숫자를 방해하지 않음 |
| 모바일·접근성 | 390px에서 잘림 없음, Enter 선택은 메인 조작 증거로 확인 | 필터 세 개 한 줄, 날짜·금액 정렬 유지 |
| 방문자·타인 | 본인만 확인, 해당 상태는 미확인. 신원 관련 변경 없음 | 방문자·타인·긴 금액 미확인 |

필수·선택적 문제 모두 0개. UX 리뷰어의 독립 코드 검토에서도 이벤트·필터·정렬·페이지 초기화·접근성 속성 변경 없음 확인. R0 종료, 수정 회차 0회. 로딩·오류·hover의 시각 상태는 미확인, 상태 로직은 변경하지 않았다.

## 검증

Node v22.23.3. 변경 파일 ESLint/Prettier·diff check 통과, 관련 Jest 2 suites/9개 통과, production build(타입 검사 포함) 통과, PC/모바일 Playwright 조작·캡처 확인. 전체 verify는 시각 전용 로컬 변경 범위로 미실행.

최초 dev 서버는 같은 워크트리의 기존 dev 잠금으로 종료되었으며 첫 캡처는 연결 거부로 실패했다. 기존 서버를 건드리지 않고 production build 후 독립 포트 3217로 검증해 성공했다. 애플리케이션 수정 재시도는 없었다.
