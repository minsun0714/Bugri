# QUIZ-CARD-ACTIONS UX/UI 리뷰

## 대상과 증거

- 검토용 사용자 가설: 본인 퀴즈를 관리하거나 공개 퀴즈를 골라 풀려는 개발자.
- 확정 요구: 모든 목록 카드의 화살표 제거와 전체 영역 접근, 내 퀴즈 우상단 설정 아이콘, 우하단 평가 유지. 후속 사용자 요청으로 내 퀴즈 높이를 추가 축소한다.
- HEAD `5a50347` 이후 미커밋 변경. QuizCard와 QuizList/AuthoringWorkspace 대상. 풀이 평가 위치·API는 변경하지 않는다.
- 독립 UX `card_actions_ux`, UI `card_actions_ui`. 새 컨텍스트 R0, 같은 리뷰어 R1. 서버 127.0.0.1:3497, 1280/320px. `/quizzes/authoring/manage?user=author&status=PUBLIC`, 태그·개발자·프로필 목록, 게스트.
- R0 제공 캡처 `/tmp/bugri-card-actions/{1280,320}-{manage,tags,developers,users}.png`. 실제 브라우저 조작과 코드 리뷰 병행. R0 캡처는 후속 높이 축소 전 버전이다.

## R0 최초 관찰

UX: 내 퀴즈는 상태·설정·평가를 구분하는 관리 목록, 공개 목록은 문제를 골라 푸는 화면으로 이해했다. 직접 320px 카드 링크→Tab 설정→Enter 관리, 게스트 여백 클릭→데모 선택→Escape→작성자 링크 이동 확인. 격리 저장 상태의 PRIVATE 여백 클릭→풀이(number 답안), PENDING→검토 확인. 75자 긴 제목 PRIVATE 카드 280×293px, 가로 넘침 없음. 독립 코드 리뷰에서 이동 분기와 독립 클릭 영역·disabled 동작을 확인했다.

UI: 굵은 제목이 먼저 보이고 설정과 평가는 각각 우상단·우하단 보조 행동으로 분리된다. 8개 캡처를 열람했고 직접 320px 긴 제목 DOM 스트레스와 카드 외곽 포커스 표시를 확인했다.

| 중복·밀도 | 화살표·하단 관리 텍스트 제거 | 상태·메타·평가 중첩 없음. 사용자 후속 요청으로 높이 추가 축소 |

## 검증 기록

- Node v22.23.3. 신규 동작 단위 테스트의 의도한 최초 실패 확인 후 구현.
- R0 관련 단위 9개, 카드 접근·평가 E2E 13개 통과. 첫 E2E에서 quiz→attempt URL 교체를 놓친 기대값과 모바일 전체 크기 링크의 중심 클릭 간섭 발견. 제목 링크의 after 영역으로 클릭 범위를 확장하고 실제 풀이 화면을 검증하도록 수정 후 통과(수정·재실행 1회).
- C1 편집 중 JSX 닫힘 구문 오류를 포맷 검사에서 발견해 즉시 수정, 재포맷·해당 ESLint 통과. 최종 전체 검증 결과는 아래 기록.
- 전체 검증 시작 후 사용자 C1 요청이 도착했다. 기존 검증을 중단하지 않고 수정했으며, 최종 소스 정적 검사는 별도로 확인한다. 최초 전체 lint 뒤 타입·단위·빌드·E2E는 C1 소스를 대상으로 실행한다.

- 첫 전체 검증은 상점 단위 2개가 5초 시간초과(311개 통과)로 중단됐다. 코드·타임아웃·기대값 변경 없이 해당 상점 11개 재실행 통과 후 최종 전체 검증을 다시 실행했다. 수정·재실행은 작업 전체 3회 내에서 수행했다. `/tmp/bugri-card-shop-retry.log`, `/tmp/bugri-card-actions-final-verify.log`. 최종 전체 단위313개·도구3개·빌드 통과, E2E197개 통과·7개 실패.

## C1/R1 최종 화면

- UI 직접 측정: 기본 PUBLIC 카드 1280px에서 높이172.28px, 320px에서164.28px. 이전 모바일194px 대비 약30px 축소. 두 태그가 두 줄이어도 기본 높이 동일.
- UI DOM 스트레스: 긴 제목·긴 한영 태그에서도 가로 넘침·설정/평가 중첩 없음, 카드 외곽 포커스 확인. 실제 저장 데이터 스트레스는 아니며 `/tmp/bugri-card-actions/compact-{1280,320}-ui.png`, `compact-320-ui-stress.png`에 기록.
- UX 두 너비 직접 조작: 여백→풀이, 설정 focus+Enter→관리, 좋아요 선택→목록 URL 유지. 320px 태그영역100.625×40px, 문서 가로 넘침 없음. `/tmp/bugri-card-actions/r1-ux-{320,1280}.png`.
- 리뷰 수정 1회(C1), 재검증 R1. 필수 미해결 없음으로 종료. UI-01은 선택 보류. PRIVATE/PENDING은 R0 직접 확인 결과를 재사용하며 C1은 해당 동작 분기를 바꾸지 않았다. 실제 스크린리더/정량 대비/실패 네트워크 직접 확인은 미실행.
