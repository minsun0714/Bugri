## R0 → C1/R1

- UX-01/UI-01(동일 필수 문제): 금액 그룹의 whitespace-nowrap가 Tooltip에 상속되어 PC 카드 밖으로 유출, 모바일 긴 두 사유 잘림.
- C1: nowrap를 금액 span에만 제한. E2E에서 Tooltip scrollWidth≤clientWidth 검사 추가. 동일4캡처를 C1으로 다시 촬영했다.
- R1: 두 리뷰어 모두 해결 확인. PC 오답2줄/복합4줄, 모바일 복합3줄로 내부 표시. 모바일 하단 Tooltip은 다시풀기·다음문제 버튼을 가리지 않는다. PC에서는 열린 동안 문제제목 일부를 덮지만 기존 일시적 오버레이이며 다음행동을 방해하지 않아 추가 결함으로 판단하지 않았다.
- 수정1회 후 필수 미해결0. 개발 Next표시가 모바일 설명 일부와 겹치는 것은 캡처 한계로 구분. 독립 실제터치·스크린리더·영문·다른높이·확대는 미확인이다.

코드 독립리뷰: 기존 지급분기/금액/멱등성 유지, 제출시 사유 고정, 복수 사유 및 레거시호환 확인. 추가 차단 결함 없음. 실행 검증은 TASKS 기록을 따른다.

후속 통합: 테마토글 dev1c5004e를3306472로 병합한 뒤 Tooltip본문/배치변경 없이 동일코드로 최종검증했다. 한국어/영어 보상E2E6개 포함 선정148개 통과. 독립캡처는 테마헤더 병합 전이며 헤더새디자인의 화면리뷰 근거로 사용하지 않는다.
