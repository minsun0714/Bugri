# HEADER-REMOVE-APPEARANCE 리뷰

- 대상: 헤더에서 학습·탐색 메뉴를 사용하는 방문자와 learner(검토용 가설). 사용자 요청에 따라 화면 설정 링크만 PC·모바일에서 제거했다.
- 증거: 현재 미커밋 코드, 전용 production 서버 `http://127.0.0.1:3109`, `/discover/developers` 및 `?user=learner`. 독립 UX/UI 리뷰어가 실제 화면을 확인했다.
- 변경 범위: `product-header.tsx`의 링크 2곳 및 settings 활성 분기 삭제. 테마 기능과 `/settings` 직접 접근 유지.

## UI R0

독립 UI 리뷰어가 1280×800, 320×800의 방문자·learner 및 모바일 메뉴를 Playwright로 캡처해 확인했다. 문제 0개.

| 관점 | 관찰 |
| --- | --- |
| 위계·목적 | 개발자 탐색 화면과 현재 메뉴 보라색 강조가 유지됨 |
| 글자·색상·일관성 | 기존 글자 크기와 버튼 표현 유지 |
| 여백·정렬·비례 | PC 메뉴와 우측 제어 정렬, 삭제 위치에 빈 요소 없음 |
| 모바일·밀도 | 로고·테마·메뉴와 사용자 제어 두 줄 유지, 메뉴 01~03과 언어 선택 잘림 없음 |
| 상태 | 방문자·learner에서 설정 링크 없음, 테마 버튼 유지 |

시각 리뷰에서 키보드·다크·직접 settings 이동은 미확인. 구현자 theme E2E에서 해당 기능을 확인했다.

## UX R0 및 종료

독립 UX 리뷰어가 1280×800·320×800 방문자/learner 헤더와 모바일 메뉴를 직접 확인했다. 필수·일반 문제 0개.

| 관점 | 관찰 |
| --- | --- |
| 목적·우선순위 | 개발자 탐색·태그 탐색·상점 메뉴와 테마 제어 유지 |
| 핵심 이동 | learner 쿼리 유지, 탐색 링크 클릭 후 메뉴 닫힘 확인. 최종 도착 URL 안정화는 미확인 |
| 중복·밀도 | 요청한 화면 설정 링크가 PC·모바일에서 제거됨 |
| 상태·피드백 | 모바일 메뉴 열기·닫기·Escape 확인 |
| 모바일·키보드 | 320px 메뉴 및 Escape 직접 확인, 테마 키보드는 구현자 E2E로 확인 |
| 방문자·본인·타인 | 방문자·learner 확인. 타인 전용 헤더 변경 없음 |

R0에서 두 역할 모두 수정 요구가 없어 수정 0회로 종료한다. 독립 코드 리뷰에서도 변경 범위 내 회귀 우려가 발견되지 않았다. 전체 제품 UX 검증을 의미하지 않는다.
