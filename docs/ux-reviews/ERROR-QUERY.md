# ERROR-QUERY 독립 UX/UI 검토

## 대상·근거

- 공개 프로필을 보는 방문자가 데스크 조회 실패에서 같은 영역의 재시도로 복구한다. 프로필·학습 활동은 유지하고 mutation 자동 재전송·입력 소실을 만들지 않는다.
- 대상은 QueryBoundary, 공개데스크 연결, 공통 QueryClient/안전한 오류메시지와 작성·프로필 입력 검증이다. 기존 시각 토큰·버튼·section을 재사용한다.
- 독립 UX/UI는 1280×800/375×800 preview 캡처를 직접 열고 코드·E2E 증거를 검토했다. 이는 실제 프로필 통합 장애 캡처와 구별한다. 구현자의 preview503/재시도 및 정상프로필 E2E6개·관련단위48개 통과.
