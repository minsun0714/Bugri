# TAG-DISCOVERY-POLISH 리뷰 및 검증

## 대상과 증거

- 사용자 목표: 헤더·홈 소진 상태에서 태그 탐색에 진입해 태그 검색, 명시적 구독, 학습 이동 및 직접 구독한 태그 관리.
- 확정 제약: 공개 퀴즈 없는 태그도 검색/구독 가능, 검색 후 자동 구독 금지, 구독 후 검색 조건 유지, 학습은 별도 행동. 실제 인증은 제외하고 기존 데모 세션만 연결한다.
- 범위: 태그 페이지와 공유 검색/메뉴의 접근성, Discovery API, 관련 문서·테스트. 다른 페이지의 로그인 게이트나 개발자·태그 조합 구독 관리는 포함하지 않는다.
- 코드: TAG-DISCOVERY-POLISH 커밋 전 diff. Node v22.23.3. 개발 서버 localhost:3002는 현재 워크트리 cwd 확인 후 사용. production E2E는 별도 3317, 전체 verify는 3337에서 실행.
- 구현 전 UI 설계: 별도 UI agent가 기존 스크린샷·토큰을 확인하고 검색→필터→결과 통합, 카드 상태·공개 수량, 44px 행동 영역을 제안했다.
- 독립 R0: 새 컨텍스트 UX/UI agent 각각 직접 Chromium 화면과 동작을 확인한다. 개발/테스트 대화 전체를 상속하지 않았으며 코드 수정·추가 위임을 금지했다.

## 구현 중 검사

- TDD: 새 API 테스트는 미지원 subscribedOnly로 실패, 컴포넌트 테스트는 첫 페이지 복귀/입력 안내 부재로 실패한 것을 확인하고 구현했다.
- 관련 단위 19개 통과, 전체 Jest 45 suites/227개 통과.
- 첫 관련 E2E는 새 테스트의 TypeScript 옵션/문법 오류로 build 차단. 테스트 작성 오류를 수정했다.
- 다음 E2E에서 Modal 취소 초점 유실과 전역 listitem 선택자에 breadcrumb가 포함됨을 확인했다. Modal을 open prop으로 유지해 닫기 초점 복구하고 결과 영역으로 테스트 선택자를 좁혔다. 기대 행동은 약화하지 않았다.
- 관련 production E2E 6개 통과. lint 및 TypeScript 통과. 최종 전체 verify 통과(아래 결과 참조).
