# DIRECT-SOLVE-STYLE 개별 풀이와 홈 스타일 통일

## 대상과 증거

- 사용자 요청: 개별 퀴즈 풀이를 홈의 풀이와 같은 스타일로 통일하며 공통 컴포넌트를 재사용한다.
- ee802fe 위 `src/components/solving/solve-screen.tsx`, `styles.ts`만 수정한다. 이미 공통 QuizPanel/AnswerForm/ResultBugri를 사용하므로 카드 내부나 풀이 로직/API는 바꾸지 않는다. direct만 있던768px 제한을 없애 공통 frame을 사용하며 홈 이동 링크를 하단 공통 보조영역으로 이동한다.
- 별도 UI 설계자가 실제 홈/개별 풀이를 비교했다. 변경 전 PC1440에서 홈 x158/1124px, 개별 x336/768px.375px에서는 둘 다335px. 제한 제거와 보조링크 톤 통일을 제안했다.
- 새 컨텍스트 UX/UI 리뷰어가 각각 Node v22.23.3·Playwright Chromium·localhost3002에서 직접 조작했다. 학습자 TypeScript 홈 및 `/solve?user=learner&quiz=seed-quiz-1`. UI1440/375/320×900, UX1440×1000·375/320×812.
- UI 증거 `/tmp/ui-direct-{home,solve}-{1440,375,320}.png`, `/tmp/ui-direct-result-{home,solve}-{1440,375,320}.png`. UX `/tmp/direct-ux-{1440,320,375}-{initial,result}.png`, `/tmp/direct-ux-home.png`. 구현자가 최종 PC 캡처를 추가 확인했다.

## 최초 관찰과 주요 흐름

- 문제를 선택해 푸는 화면으로 식별되며 제목→문제→선택지→제출 순서가 명확하다. 하단 홈 링크는 보조 행동이다.
- UX는 각 너비에서 키보드 Space 선택→Tab 제출→정답/내 답/해설→다시 풀기(선택 초기화)→홈 이동을 직접 확인했다. UI는 홈/개별 양쪽 선택·제출·정답 결과까지 비교했다.

- 필수/일반 UX·UI 문제0개. R0에서 종료, 수정 회차0회.

- Next 개발 오버레이는 제품 UI 평가에서 제외했다.
