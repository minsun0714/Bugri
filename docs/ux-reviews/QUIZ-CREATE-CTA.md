# QUIZ-CREATE-CTA

## 대상과 증거

- 목표: 내 퀴즈에서 중복 없이 새 퀴즈 생성 화면에 진입한다. REQ-02/AC-02e의 생성/저장 목록 분리는 유지한다.
- 범위: `quiz-list.tsx` 상단 CTA 스타일과 빈 상태 중복 링크, 관련 회귀 테스트. 공통 UI·API 변경 없음.
- localhost:3199, `/quizzes/authoring/manage?user=learner`(0개), `user=author`(2개). 변경된 미커밋 코드 기준.
- 캡처: `/tmp/bugri-cta/{desktop,mobile}-{learner,author}.png`, 전체 페이지, viewport 1440×900 / 390×844. 로컬 임시 증거이며 저장소에는 포함하지 않는다.
- 구현자 Playwright 직접 조작: 4상태에서 생성 링크 1개, focus→Enter→사용자 쿼리를 유지한 생성 화면→학습 내용 입력 표시 확인.
- 독립 UX/UI 리뷰어는 새 컨텍스트에서 네 캡처를 직접 열어 평가한 뒤 코드 diff 확인. 브라우저 직접 조작은 하지 않았으며 이동 증거는 구현자 결과를 사용했다. UX 리뷰어가 코드·테스트도 독립 검토했다.

## 설계 논의

별도 설계 sub-agent는 목록 유무와 무관하게 제목 오른쪽 CTA 한 개를 유지하고 빈 상태 action만 제거하도록 권장했다. 공통 primary 스타일, 장식용 + 아이콘, 최소44px 높이와 reduced-motion transform 억제를 적용했다.

## 문제와 회차

UX/UI 모두 필수·일반 문제 0개. 수정 C 회차 0회, R0에서 종료했다. 미해결 문제 없음. 스크린리더·확대·390px 미만·로딩/오류 및 UI 기본/hover 화면은 독립 리뷰 미확인이다. 이는 해당 상태까지 검증 완료했다는 의미가 아니다.

## 검증

- Node v22.23.3.
- 회귀 테스트 최초 작성에서 Jest each 배열 인자 오류를 수정(실패 처리 1회). 이어 빈 목록 링크 2개라는 의도한 실패 확인 후 구현.
- 관련 Jest 6개 통과, 변경 TS/TSX ESLint·Prettier 통과.
- 최초 타입 검사에서 생성된 LayoutProps 부재로 실패. `npx next typegen` 후 전체 타입 검사 통과(환경 복구 1회).
- PC·모바일 직접 Playwright 생성 이동 4상태 통과.
- 관련 작성 E2E 결과는 아래에 기록한다. 좁은 UI 수정의 로컬 완료 검증이며 전체 verify는 실행하지 않는다.

- `npm run test:e2e -- tests/e2e/quiz-authoring.spec.ts`: 12개 통과. 빌드 후 3109 포트 선점으로 최초 서버 실행이 실패했으나 공식 래퍼가 3110으로 자동 재시도하여 통과했다. 다른 서버는 중단하지 않았다.
- `git diff --check` 통과. 최종 검증 후 변경은 이 기록과 TASKS 문서뿐이다.
