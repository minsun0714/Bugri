# STREAK-SUMMARY-CENTER — 요약 가로·세로 중앙 정렬

- 사용자 승인: 버그리와 연속 학습·일수·오늘 상태 묶음을 데스크톱 왼쪽 영역의 가로·세로 중앙에 배치한다. 내부 캐릭터 왼쪽/텍스트 오른쪽 구성과 모바일 상단 배치는 유지한다.
- 구현 전 UI 설계 위임 후 `streak-summary.tsx`의 왼쪽 `role=status`에 `lg:self-center lg:justify-center`를 적용했다. 날짜·집계·초점·우측 고정 높이는 변경하지 않는다.
- 코드: `c869865` 이후 해당 클래스 변경. 독립 새 컨텍스트 UX·UI 리뷰어에게 production `127.0.0.1:3327`, 390/768/1280 로그인 및 제출 경로를 제공했다. 수정 0회 기준 R0 진행 중.
- Node v22.23.3. 최초 관련 E2E 실행은 서버 시작 120초 제한으로 중단됐다. 수동 `npm run build` 재실행은 정상 통과했고 최신 가로·세로 정렬을 포함한 서버를 시작했다. 검사를 약화하거나 타 서버를 재사용하지 않았다.

## R0 결과

- UI: 1280px 세로 중심 y364px 일치, 왼쪽 묶음 가로 중심 x276.656px와 열 중심 x276.664px 일치. 달력·월 목록·연도 메뉴 3상태에서 그리드 높이 444px 유지. 768/390 세로 배치와 내부 버그리 왼쪽·텍스트 오른쪽 구성이 유지됐다. 캡처 `/tmp/center-ui-{1280,768,390}-{day,month,year}.png`.
- UX: 1280/390 빈 상태 및 실제 number 제출 후 1일 연속·오늘 완료·1개 반영을 직접 확인. 날짜 제목→월→연도 메뉴 진입 확인. 월 복귀 스크립트는 locator timeout으로 직접 미확인으로 남기며 제품 결함으로 단정하지 않았다. 캡처 `/tmp/center-ux-{empty,complete}{1280,390}.png`.
- 목적·정보 위계·밀도·상태·모바일에서 해당 정렬 변경의 회귀를 발견하지 않았다. 별도 코드 리뷰도 두 lg 클래스만 변경됐음을 확인했다. 방문자·타인·전체 키보드·오류/로딩·긴 일수는 직접 미확인이다.
- 두 리뷰어 R0에서 범위 내 필수 수정 없음, 수정 0회. 관련 E2E 재실행 6개 통과. 이후 사용자가 승인한 달력 시각 변경을 포함한 마지막 전체 verify를 완료 근거로 사용한다.
