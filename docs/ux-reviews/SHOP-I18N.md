# SHOP-I18N 독립 리뷰

## 범위와 환경

상품 15종의 한국어/영어 표시, 설명 검색·이름 정렬, 장착 미리보기와 보관함. 기존 레이아웃·구매/배치 규칙 유지. Node v22.23.3, 자체 production 서버 3465, Chromium 1280×900 및 390×900. 새 컨텍스트의 UX·UI 리뷰어가 실제 화면을 먼저 확인하고 코드와 대조했다. 구현 전 UI 설계 검토는 기존 토큰/레이아웃과 자연 줄바꿈 유지 권고였다.

## R0 UX

- Shop/상점 제목·잔액·상품 이미지·가격·구매 버튼으로 목적과 행동 식별. PC 첫 화면에 검색·정렬·카테고리와 첫 상품 행이 표시된다.
- 두 viewport에서 sage 설명 검색→1개, 이름순→Blue plant, 미리보기→구매→보관함을 직접 수행했다. Owned 비활성·Equip·한국어 전환 후 블루 화분을 확인했다.
- 번역 때문에 안내문/단계가 추가되지 않았다. 모바일 검색·정렬·카테고리 조작, 가로 넘침 없음, Escape 모달 닫기, 미리보기 접근성 이름을 확인했다.
- 이전 seed와 카탈로그의 ID·한국어 이름/설명·카테고리·가격·순서 15개 전부 동일함을 독립 추출 비교했다. API 복사본의 문구만 바꾸며 query key/구매 로직 유지. locale 이외 localStorage가 언어 전환 전후 동일했다.
- 필수 문제 0. 기존 모바일 첫 화면의 상품 행동이 스크롤 아래에 위치하는 배치는 번역 회귀가 아니므로 변경하지 않는다.

## R0 UI

- ko/en 1280·390 전체 상품 목록 및 Cream studio desk/크림 스튜디오 책상 모달을 독립 브라우저로 확인했다.
- 영문 설명 1~2줄이 가격·버튼과 겹치지 않는다. 모바일 모달의 긴 영문 제목은 2줄로 자연스럽게 표시되며 닫기 버튼 공간을 유지한다.
- 기존 타이포그래피·여백·색상·가격/버튼 위계 유지. 3열→1열, 카테고리 줄바꿈, 모바일 검색·정렬 세로 배치 정상. 필수 시각 결함 0.
- 캡처: `.bugri-hooks/shop-i18n/{en,ko}-{1280,390}.png`, `trial-{1280,390}.png`, `ui-modal-{en,ko}-{1280,390}.png`.

## 종료와 한계

R0 종료, UI 수정 0회, 미해결 필수 문제 0. 본인 데모 사용자 흐름을 직접 확인했다. 방문자/타인 공개 데스크, 서버 실패 상태, 전체 키보드 순회, 스크린리더 실제 발화, 200% 확대·다크 테마와 3D 배치 제스처는 이번 독립 화면 리뷰에서 미확인이다. 공통 상품명 경로는 정적 검토했다. 테스트 성공을 시각 판단의 근거로 대체하지 않았다.

## dev 통합 정적 독립 검토

`d2c10a1` 병합 후 UX 리뷰어가 별도로 확인했다. 기능의 번역 키/값 전부 보존, dev 대비 제거된 항목은 카탈로그로 이동한 상품명15개뿐이며 테마 번역5개는 유지한다. 카탈로그/상점 구현은 병합 전후 동일하다. API·ARCHITECTURE·TASKS의 양쪽 문서와 테마 리뷰 기록 보존, PC 언어 선택과 테마 토글/모바일 언어 선택 공존, 충돌마커 없음과 diff check를 확인했다. 정적 결함0, 통합 런타임 결과는 TASKS에 별도 기록한다.
