# PROFILE-PR-INTEGRATION — PR16 최신 dev 통합

## 범위·증거

PR 생성 후 origin/dev6095945와의 충돌 해결. dev의 BugCoin 내역/필터/페이지네이션·개인관리 데스크 링크와 프로필 브랜치의 빈 편집항목 제거·공개 프로필 편집을 함께 보존한다. 새로운 화면 설계는 하지 않는다.

새 컨텍스트 pr_integration_ux·pr_integration_ui가 격리127.0.0.1:3158의 `/my?user=author`, `/users/bugri-author?user=author`를 실제 관찰한 뒤 코드를 확인했다. 검토 목적은 본인 소개·링크 편집 및 개인 내역/데스크 이동. 테스트 성공을 독립 판단 근거로 사용하지 않았다.

| ------------- | -------------------------------------------------------- |
| 목적·대상     | 마이페이지 개인 관리와 공개 ID·데스크·퀴즈 화면 구분     |
