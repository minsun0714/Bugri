# ERROR-PAGES 독립 UX/UI 검토

## 대상과 증거

- 방문자·데모 사용자가 없는 URL/렌더링 예외에서 홈 이동 또는 재시도로 복구한다. Next 파일 규칙, 원문 오류 비노출, provider 없는 global 화면을 유지한다.
- 대상: 이 작업의 app 오류 3파일, components/errors, 오류 테스트. 1280×800/375×800 캡처는 `/tmp/bugri-error-pages-captures/`에 보존한다.
- 독립 UX/UI가 각각 실제 PNG 4장을 먼저 보고 코드·E2E 로그를 검토했다. 직접 브라우저 조작은 하지 않았다. 구현자 E2E에서 홈 이동·Enter 재시도 성공 확인.
- global-error는 provider 없는 정적 문서와 공유 UI만 확인했다. 실제 root-layout 오류 발생/복구·스크린리더 음성은 미확인이다.

| 관점 | UX 근거 | UI 근거 |
