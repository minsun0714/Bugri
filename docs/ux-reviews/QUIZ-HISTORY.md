# QUIZ-HISTORY 독립 UX·UI 리뷰

## 대상과 증거

- 목표: 본인 제출 기록 최신순 탐색 → 오답의 당시 답·정답·해설 확인 → 조건 유지 복귀 또는 새 Attempt 재도전.
- 확정: 개인 전용, 전체/정답/오답, 20개 페이지, 삭제·비공개 내용 비노출과 기록 보존. 통계·검색·공개 프로필·상점·전역 토큰 변경 제외.
- 대상: QUIZ-HISTORY 미커밋 구현. 독립 dev 서버 `127.0.0.1:3149`. 더미 learner 기록 43개는 리뷰용 브라우저 fixture에만 주입; 제품 seed에 추가하지 않음.
- 새 컨텍스트 UX·UI 리뷰어 각각 1명. Playwright 직접 조작, PC 1280×900/모바일 390×844, ko/en. 구현자 테스트 성공을 최초 판단 근거로 사용하지 않음.

## UI 최초 관찰 및 평가

화면은 본인 완료 목록의 정오답·시간을 비교하고 상세에서 과거 답과 정답을 대조하는 용도로 읽혔다.

| 관점        | 근거·판단                                                                    |
| ----------- | ---------------------------------------------------------------------------- |
| 위계        | 제목→필터→기록 제목→배지/날짜. 상세 결과→질문→내답/정답→해설 순서가 구분됨   |
| 타이포·여백 | 목록 구분선/행간, 상세 답안 영역과 해설 분리. 작은 날짜가 보조 정보로 읽힘   |
| 색상·일관성 | 기존 purple active filter/link, 정답 green/오답 pink 배지와 텍스트 동시 제공 |
| 정렬·비례   | 중앙 PC 패널·모바일 inset 일관. 답안 PC 2열→모바일 1열                       |
| 모바일      | 목록 제목은 정상 줄바꿈. 상세 긴 제목 가로 넘침 UI-01 발견                   |
| 상태        | 빈 목록 상태·홈 행동, 타인 접근 오류의 재시도·목록 복귀 확인                 |

직접 캡처: `/tmp/ui-{ko,en}-{false,true}-{list,detail,normal,denied}.png`, 실제 빈 상태 `/tmp/ui-{ko,en}-empty-real.png`. `empty.png`는 정답 목록이라 빈 상태 근거에서 제외한다.

## 후속 리뷰 — 헤더 정렬·홈 스타일

### 사용자 피드백과 이전 리뷰 누락

헤더/본문 폭 불일치와 큰 외곽 컨테이너의 상투적인 인상은 **사용자가 지적한 문제**다. 앞선 리뷰어가 발견한 것으로 소급 기록하지 않는다. 이전 리뷰는 개별 컴포넌트 가독성·overflow·기능 흐름을 확인했지만, 로그인 홈과 나란히 비교해 공통 좌우 정렬축·브랜드 일관성을 검사하지 못했다. 기존 ‘필수 문제 없음’은 이 누락을 포함한 완전한 화면 품질 보장이 아니었다.

별도 설계 sub-agent가 1440px 실제 화면을 비교했다. 홈은 x158~1282·폭1124px, 기존 내역은 x336~1104·폭768px여서 좌우가 각각178px 안쪽이었다. 모바일은 외곽 카드의 추가 padding으로 긴 제목의 가독폭도 줄었다. 근거: `/tmp/design-home.png`, `/tmp/design-history-filled.png`, `/tmp/design-history-mobile.png`.

### 수정과 검사 기준

- 본문 `max-w-3xl`과 목록 외곽 흰 카드 제거. 헤더/홈과 동일 ProductLayout 콘텐츠 폭을 사용.
- 홈의 40px Bugri·24px 제목, 보라 배경의 라임 선택 pill, 기존 정오답 배지와 얇은 구분선 사용. 캐릭터는 장식이며 접근성 트리에서 숨김.
- PC 제목·정오답·시간 3열, 모바일 제목 전체폭 아래 정오답/시간. 화면 데이터/기능/헤더/홈/전역 토큰은 유지.
- 새 컨텍스트 독립 UX·UI 리뷰어에게 실제 홈 비교·좌우 좌표·빈/데이터 상태·긴 제목·한영·키보드를 요청. 구현 전 설계 검토와 구현 후 독립 리뷰를 구분.
- 구현자 캡처: `/tmp/history-redesign-desktop.png`(1440×1000), `/tmp/history-redesign-mobile.png`(390×844), 테스트 브라우저에만 8개 기록 fixture 주입. 제품 seed 변경 없음.
