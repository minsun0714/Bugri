# P08-DESK-SHARED UX/UI 리뷰

## 대상과 증거

- 사용자 목표: `/my/desk`에서 상점 장착해보기와 같은 직접 선택·드래그·회전·겹침 메뉴·휠 확대를 사용한다. 하단 선택/높이/배치/안내 패널 제거, 보유 상품 유지, 책상과 아이템 독립 이동은 사용자 확정 요청이다.
- 기준: `08cd072` 위 미커밋 구현. R0 서버 `http://127.0.0.1:3225`, 화면 캡처 `/tmp/bugri-desk-shared/{empty,menu,error,equipped}-{1280,390}.png`. viewport 1280×1000/390×1000 전체 페이지. learner 본인 상태.
- C1은 오류 본문 색상·줄바꿈 변경. 최신 빌드 캡처 `r1-error-{1280,390}.png`, `r1-saved-{1280,390}.png`. R0 장착 캡처 이후 상품·캔버스 코드는 동일하다.
- UX/UI 각각 새 컨텍스트에서 독립 리뷰. UX는 모바일 기본책상 키보드 선택→이동→회전→Enter 저장→새로고침→재선택을 직접 수행해 X 0.10/15° 복원을 확인했다. UI는 캡처를 직접 확인했다. 구현자는 두 크기 오류 주입→재시도→오류 제거도 직접 확인했다.

## UX R0/R1

| 관점             | 판단·관찰 근거                                                                                                    |
| ---------------- | ----------------------------------------------------------------------------------------------------------------- |
| 목적·대상        | 내 데스크 제목·본인 공개 프로필 링크와 보유 상품 카드로 편집과 상품 관리가 구분된다.                              |
| 첫 화면·우선순위 | 두 viewport 모두 편집 캔버스가 먼저, 보유 상품 제목·필터가 이어진다.                                              |
| 핵심 행동        | 독립 UX 리뷰어가 키보드 기본책상 편집·저장·복원을 직접 완료했다.                                                  |
| 밀도·중복        | 하단 선택·높이·저장·안내 패널 없음. 캔버스와 보관함 경계는 유지된다.                                              |
| 상태·피드백      | 저장 성공은 sr-only, 실패 시 변경 유지 설명과 재시도·취소 노출. R1 저장 후 오류 영역 제거 확인.                   |
| 모바일·접근성    | 캔버스 설명 연결과 키보드 선택/이동/회전/저장/취소를 확인. 모바일 메뉴 네 항목은 화면 안에 들어온다.              |
| 본인·타인        | 본인 화면과 공개 프로필 복귀 링크 확인. 공개 프로필 저장 복원은 구현자 E2E/API 근거이며 독립 실조작은 미확인이다. |

R0/R1 필수 UX 문제 0개. 독립 코드 리뷰는 공통 EditableDeskScene과 좌표 보정·서비스 검증 후 일괄 저장을 확인했다. 보유 키보드가 있는 R0 캡처에서 장착 표시·해제와 선택 조작이 공존함을 확인했다.

## UI R0/R1

| 관점              | 관찰 근거                                                                        |
| ----------------- | -------------------------------------------------------------------------------- |
| 위계·비례         | 캔버스→보유 상품 흐름 유지, 정상 상태 불필요한 조작 패널 없음.                   |
| 정렬·여백         | 캔버스와 목록 경계가 정렬되며 저장 성공 후 오류 영역 여백이 제거된다.            |
| 타이포그래피·색상 | R0 오류 coral 대비 2.61:1 문제 발견. R1 foreground 대비 14.85:1로 해결.          |
| 일관성·모바일     | 공유 선택 테두리·회전·메뉴 형태 유지. 모바일 오류 문장을 어절 단위로 줄바꿈한다. |
| 보유 상품         | 장착 키보드 선택 아이콘과 보유상품 카드가 두 크기에서 잘림 없이 표시된다.        |

## 회차와 종료

| 회차  | 결과                                                      | 한계                                                                    |
| ----- | --------------------------------------------------------- | ----------------------------------------------------------------------- |
| R0    | UX 필수 문제 없음, UI-1 필수·UI-2 선택적 개선             | 실제 터치·스크린리더 음성·여러 아이템 모서리 선택 독립 미확인           |
| C1/R1 | UI 수정 1회, 두 역할이 대비·줄바꿈 해결 및 회귀 없음 확인 | R1은 캡처 리뷰. 실패 재시도는 구현자 직접 증거이며 독립 재실행하지 않음 |

구현자 관련 E2E 16개는 직접 선택·드래그·회전·높이·겹침·휠 확대·독립 이동·저장·공개 복원을 검증한다. API는 기본/장착 책상, 사용자 격리, 실패 원자성, 공개 복원, 이전 책상 요청 거부를 검증한다. 전체 검증 결과는 TASKS에 별도로 기록한다.
