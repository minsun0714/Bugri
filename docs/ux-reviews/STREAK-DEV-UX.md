# STREAK-DEV-UX — dev 병합 후 스트릭 UX 점검

## 대상과 증거

- 검토용 사용자 가설: 홈에서 오늘 학습 여부를 파악하고 퀴즈 한 문제를 완료해 연속 학습을 이어가려는 더미 로그인 사용자.
- 확정 제약: 퀴즈 위 현재 연속일·최근 7일·오늘 상태, 방문자 스트릭 비노출, 사용자 시간대 기준 집계. 스트릭 문구·표현만 수정하며 상세 기록/시간대 설정·타 기능은 제외한다.
- R0 코드: `0810db0`, 경로 `/`, 전용 서버 `http://127.0.0.1:3327`. 새 컨텍스트 독립 리뷰어가 Playwright로 1280×900/390×844 및 격리된 learner 상태를 직접 조작했다. dev 변경은 리뷰 지침이며 앱 UI 변경은 없다.
- C1: `streak-summary.tsx`의 연속 중단 상태 문구 분기와 관련 단위/E2E 테스트. R0 캡처는 수정 전 증거다.

## 최초 관찰과 흐름

리뷰어는 화면만 보고 연속 학습 요약 다음 오늘의 퀴즈/답안으로 이어지는 흐름을 식별했다. 로그인 → number 선택 → 제출 → 1일 연속/오늘 완료 → 다음 문제 → 블록 스코프 문제를 직접 확인했다. 어제까지 2일 상태와 3일 전 기록만 있는 중단 상태도 별도로 주입·조회했다.

| 방문자·본인·타인 | 부분 확인 | 방문자 스트릭 비노출과 learner 개인 요약 확인. 타인 공개 스트릭은 범위 밖 |

## 문제 목록과 처리

| ID | 위치·상태 / 관찰 사실·가설 | 사용자 영향·우선순위 | 개선안·해결 조건 | 메인 처리·이유 | 재검증 |
| --- | --- | --- | --- | --- | --- |
| S-01 | 과거 기록은 있으나 streak=0일 때 ‘한 문제 풀고 첫 기록’ 표시. 메인이 먼저 발견하고 리뷰어가 독립 브라우저로 재현 | 기존 기록이 사라진 것으로 오해할 수 있는 일반 사용성 문제 | 기존 기록이 있으면 재시작 안내, 없으면 최초 안내. 제출 후 1일 전환과 기존 날짜 체크 유지 | 수정 C1: ‘오늘부터 다시 / 한 문제로 다시 시작해요’. API·집계 규칙 유지 | R1 실제 화면에서 해결 확인 |

로딩/일반 오류는 문구에 ‘연속 학습’이 포함되어 제목 숨김만으로 맥락 손실 문제를 단정하지 않았다. TIMEZONE_REQUIRED의 설정 경로는 미구현 후속 범위이며 이번에 새 정책이나 설정 기능을 추가하지 않는다. 오류 화면은 R0에서 브라우저 직접 재현하지 않았고 코드·기존 단위 테스트로만 확인했다.
