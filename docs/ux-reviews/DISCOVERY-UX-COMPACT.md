- UX R0: 한국어 모바일 6상태와 데스크톱 탐색·태그, 영어 모바일 개발자·검색 캡처. Playwright 직접 탐색→퀴즈 링크→검색→URL 유지→구독 패널. R1: 모바일 검색 펼침/접힘/초점/검색어 유지/초기화 직접 조작.

## 최초 관찰과 관점별 근거

두 리뷰어는 개발자/태그를 골라 공개 퀴즈로 이동하는 화면으로 이해했다. 카드의 별도 퀴즈 링크, 상세의 작성자와 태그명이 대상과 다음 행동을 식별한다.

| 관점 | UX 관찰 | UI 관찰 |
| --- | --- | --- |
| 목적/대상 | 작성자 ID·태그명이 조회 대상을 식별 | 제목→검색→결과 위계 명확 |
| 우선순위·첫 화면 | 한국어 모바일 상세에 필터와 문제 노출 | 태그명 강조·퀴즈 제목 위계 유지, 영어 모바일 UI-01 |
| 핵심 행동 | 별도 퀴즈 링크로 상세 직접 진입·검색 초점 확인 | 링크의 색+밑줄로 구독 버튼과 구분 |
| 중복·밀도 | 반복 제목 제거·검색 기본 접힘 | 카드 간격 일정, 칩 줄바꿈 겹침 없음 |
| 상태·피드백 | Java 0개·빈 상태·복귀 제공, UX-01 | 선택 칩 배경 구분, 수량과 빈 안내 일치 |
| 모바일·키보드 | 390 가로 넘침 없음, 열기 시 초점 직접 확인 | 한영 390/1280, 직접 키보드·대비 수치 측정 미실행 |
| 방문자·본인·타인 | friend 타인 및 구독 패널 직접 확인 | friend 캡처 확인. 다른 상태는 독립 화면 리뷰 미확인 |

독립 리뷰의 한계를 구현자 E2E 성공으로 덮어쓰지 않는다. 구현자 관련 E2E는 게스트 명시 선택, 구독 저장/해제/실패, 키보드, 빈 상태, URL 복원과 풀이 이동을 별도로 확인했다. 최종 검사 결과는 [TASK](../tasks/DISCOVERY-UX-COMPACT.md)에 기록한다.
