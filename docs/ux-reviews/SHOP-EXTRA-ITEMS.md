# SHOP-EXTRA-ITEMS

## 범위와 설계

카테고리별 새 상품 1개씩 총 5개를 추가한다. 기존 공통 모델·투영·조작 경로를 재사용하며 표면 색만 바꾼다. 오션 키보드20, 스카이 모니터25, 민트 책상30, 블루 화분5, 노을 작업실20 BugCoin으로 합계100이다. 기존 데이터·지급 정책은 변경하지 않는다. 모니터 화면과 식물 잎 색은 보존한다. Canvas와 SVG fallback 모두 새 ID를 지원한다.

별도 컨텍스트 UX 리뷰어가 624fa40 이후 변경의 production3427에서 1280×900/390×900 화면을 직접 Playwright로 조작한 뒤 코드를 검토했다.

| 관점 | 관찰 근거 |
| --- | --- |
| 목적·우선순위 | 상점·잔액·필터가 상품 위에 있고 이름·가격·미리보기/구매 행동을 식별할 수 있다. |
| 핵심 행동 | 각 카테고리3개, 새5개 미리보기→구매→장착 완료. 기본 책상은 교체 버튼으로 진행한다. |
| 밀도·일관성 | 기존 카드와 버튼 구조를 재사용하며 설명을 추가하지 않는다. |
| 상태·저장 | 새로고침 후 잔액0, 공개 데스크에서 새4개 이름·위치·15°회전과 노을 배경 확인. |

## 독립 UI R0

별도 컨텍스트 UI 리뷰어가 동일 서버에서 1440×1000/390×844의 새5개 미리보기→구매→장착과 전체 구성을 직접 관찰한 뒤 모델·색상 diff를 검토했다.

| 관점 | 관찰 근거 |
| --- | --- |
| 위계·글자 | 상품 그림→이름→가격→행동 순서로 읽히며 모바일 이름 한 줄, 버튼 충돌 없음. |
| 여백·정렬 | 데스크톱3열·모바일1열의 그림/버튼 정렬 일관, 모달 하단 구매 버튼 잘림 없음. |
| 색·비례 | 민트 상판·다리, 청록 키보드, 하늘색 모니터 프레임, 블루 화분이 노을 방과 구분된다. |
| 공간 표현 | 벽/바닥 경계가 이어지고 책상 다리 끝과 그림자가 맞으며 소품이 상판 위에 놓인다. |
| 상태·일관성 | 구매/장착 완료 및 장착 중 버튼 확인. 공통 색상 매핑·모델 경로 사용. |

필수·일반 문제0, 수정0회. 증거 `/tmp/shop-extra-ui-desktop.png`, `/tmp/shop-extra-ui-equipped-0.png`~`-4.png`, `/tmp/shop-extra-ui-mobile-{card,preview}-0.png`~`-4.png`, `/tmp/shop-extra-ui-mobile-equipped-4.png`. 초기 전체 캡처 일부는 SVG fallback이며 후속 캡처는 Canvas 안정화 후 확인했다. 실제 터치 기기·스크린리더·모든 각도/이동 조합은 확인하지 않았다.
