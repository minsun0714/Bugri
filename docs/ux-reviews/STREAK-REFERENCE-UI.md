# STREAK-REFERENCE-UI — 숫자와 요일 캡슐 재설계

## 대상과 증거

- 사용자 가설: 로그인 홈에서 학습 상태를 확인하고 퀴즈 한 문제를 완료해 연속 기록을 이어가려는 사용자.
- 사용자 승인 방향: 인프런의 요일 캡슐, 듀오링고의 성취 숫자 강조를 참고한다. 확정 제약은 최근 7일/개인 학습일 집계/비로그인 비노출/퀴즈 위 요약이다. 아이콘·간격·비율은 구현자 선택이며 리뷰 대상이다.
- 참고: [듀오링고 공식 공개 화면](https://blog.duolingo.com/improving-the-streak/), [인프런 공식 주간 학습 카드](https://www.inflearn.com/notices/679367). 과거 공개 화면을 직접 열어 확인했으며 현재 로그인 UI와 동일하다고 주장하지 않는다. 외부 서비스의 보호 아이템/주간 정책/브랜드 자산을 복제하지 않는다.
- 코드: `ad58069` 이후 `src/components/streak/streak-summary.tsx` diff. API·집계 변경 없음. 서버 `http://127.0.0.1:3327`.
- 기존 단위 5개/E2E 2개 통과. 구현자가 격리 브라우저에 최근 30일 중 25일/24일 fixture를 넣어 5일 완료·4일 유지 화면을 촬영했다. 캡처 `.bugri-hooks/previews/streak-data/`.
- R0 새 컨텍스트 독립 리뷰 완료. 리뷰어는 화면을 먼저 보고 1280×900/390×844 및 640/768 중간폭에서 실제 조작했다.

## 최초 관찰과 흐름

리뷰어는 학습자 홈에서 연속 학습 상태 확인 후 아래 퀴즈에 답하는 흐름으로 이해했다. 데모 로그인→number 선택→제출→1일/오늘 체크 갱신, 모바일 키보드 Space→Tab→Enter 제출을 직접 수행했다. 최초·재시작·어제4일·오늘5일과 learner↔friend 전환도 확인했다.

## 관점별 평가

| 관점 | 판단 | 관찰 근거 |
| --- | --- | --- |
| 목적/대상 | 문제 없음 | 연속 학습→오늘 퀴즈 목적을 화면에서 식별 |
| 정보 우선순위·첫 화면 | 선택적 개선 | 데스크톱/640/768에서 제출까지 노출, 390에서 질문/선택지 보이나 제출 아래 걸림 |
| 핵심 행동 | 문제 없음 | 별도 화면 경유 없이 직접 선택·제출 |
| 밀도·중복 | 선택적 개선 | 숫자/주간이 묶이고 불꽃이 보조 강조로 작동하나 모바일 카드254px |
| 상태·피드백 | 문제 없음 | 최초/재시작/4일 미완료/5일 완료 구분 및 제출 즉시 갱신 |
| 모바일·키보드 | 확인 범위 내 문제 없음 | 390/640/768 잘림 없음, Tooltip focus 및 키보드 답 제출 직접 확인 |
| 사용자 상태 | 문제 없음 | 방문자 비노출, learner↔friend별 개인 상태 복원 직접 확인 |

오류/재시도는 코드만 확인했으며 실제 장애 주입·스크린리더 낭독·장기 자릿수 스트릭은 미확인이다.
