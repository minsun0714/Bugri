# TAG-COUNT-LINK

## 대상과 증거

- 태그 탐색에서 공개 퀴즈 수를 눌러 해당 태그의 공개 퀴즈 목록을 보려는 방문자/회원. 사용자 요청으로 #아이콘을 학습자 아바타와 같은 테마 lime/55 배경으로 바꾸고 텍스트였던 수량을 링크로 연결한다.
- 기존 `/tags/[hashtagId]/quizzes`와 빈 목록 화면을 사용한다. 제목과 같은 catalogHref를 공유하여 사용자·검색·페이지·구독 필터를 유지한다. 개발자 카드나 퀴즈 목록은 수정하지 않는다.
- 기준 c342faa + search-results.tsx/styles.ts 및 관련 테스트. 신규 공통 UI/API 변경 없음. UI 설계 전담 에이전트가 기존 quizLink/44px 타깃 재사용과 lime 배경을 확인했다.
- 격리 복제 `/tmp/bugri-tag-card-review`, `http://127.0.0.1:3220`. 캡처 `/tmp/bugri-tag-count/tags-{1280,390}.png`: viewport 각너비×900, fullPage. 현재 미커밋 앱 코드와 동일하다.
- 구현자 Playwright 직접: 각 폭에서 Web 공개 퀴즈 2개 포커스→Enter→태그목록 헤딩 확인. 방문자 Java 공개 퀴즈 0개 클릭→user 쿼리 없는 빈 목록 확인.

| UX 상태 | 공개 퀴즈 없음/1개/2개 및 구독 상태 구분. Java 빈 목록 이동은 구현자 조작 증거로 확인. |

리뷰어 직접 조작·hover/focus 외형·로딩/오류 상태는 미확인이고 실제 이동은 구현자 Playwright 및 E2E 근거와 구분한다. 구현자 외 정적 검토에서 catalogHref 공유·게스트 문맥·기존 quizLink 재사용 확인.

C1은 사용자 요청으로 bg-lime에서 bg-lime/55로 농도만 낮춘 변경이다. 개발자 탐색 학습자 아바타의 배경 클래스와 같으며 리뷰어 발견 문제로 기록하지 않는다. 캡처는 C1으로 덮어썼고 두 폭 링크 이동을 다시 확인했다. 동일 리뷰어 R1에서 두 폭 최신 캡처의 연한 배경과 보라 # 구분, 위계·정렬·모바일 회귀 없음 확인. 사용자 수정1회, 미해결 문제0개.
