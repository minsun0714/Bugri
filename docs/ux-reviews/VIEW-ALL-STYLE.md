# VIEW-ALL-STYLE

## 범위·설계

전체 보기류를 보라색 편집과 구분하고 사이트 전체에서 같은 중립색 액션으로 표시한다. 소스 검색으로 프로필전체보기, 내구독전체보기, 검색빈상태 전체태그/개발자보기, UI전시 더보기를 확인했다. 공통 `viewAllAction`은 muted 기본/foreground hover·포커스,44px높이,14px글자,배경/그림자없는 형태다. 전시 문구는 전체보기로 통일하고 장식화살표는 제거한다. 링크·모달·검색초기화 의미와 동작은 유지한다. ‘전체’ 필터나 다른 편집/구독 버튼은 변경하지 않는다. UI디자이너에게 먼저 시각 설계를 위임했다.

## 검증 환경

첫 시도는 머신 load average56.62 상태에서 Jest의 기존 카탈로그 테스트5초타임아웃1건 및 E2E webServer의 빌드포함120초준비시간초과가 발생했다. 테스트/타임아웃 조건은 변경하지 않고 순차 Jest→production빌드→1worker E2E로 재실행했다. 임시 Playwright설정은 기존설정을 상속하고 서버명령에서 이미완료한 빌드만 분리했다. 준비/테스트타임아웃 및 모든 기대는 보존했으며 임시설정은 삭제했다. 수정/재실행1회, 재시도 모두통과.

## UI R0

새컨텍스트 UI리뷰어가16개 실제캡처를 먼저 보고 metrics 및 diff를 확인했다. 프로필의 보라색 편집3종과 회색 전체보기가 구분되고 콘텐츠 제목보다 약한 위계를 유지한다. 네화면의14px/44px/중립색 일관성, 제목오른쪽·구독목록하단·빈검색중앙의 문맥적배치,320px 한줄문구와겹침없음,진한포커스테두리를 확인했다. 화살표·밑줄·입체그림자 제거로 주요보라버튼과 경쟁하지 않는다. 수정필요문제0개. 직접클릭/키보드탐색·실제hover·타인/게스트·미사용개발자검색분기는 UI리뷰어미확인이다.
