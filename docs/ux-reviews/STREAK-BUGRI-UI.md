# STREAK-BUGRI-UI — 버그리 중심 스트릭

## 대상과 증거

- 검토용 사용자 가설: 홈에서 오늘 완료 상태를 확인한 뒤 퀴즈를 풀어 개인 기록을 이어가려는 더미 로그인 사용자.
- 사용자 확정 방향: 공통 버그리 활용, 비인터랙티브 주간 표시, 완료 중복 강조 축소, 명확한 날짜 범위. 최근7일·집계·개인 격리는 유지하며 상세 기록/설정은 후속 범위다.
- 코드: `e89d103` 이후 `src/components/streak/streak-summary.tsx` diff. 공통 Bugri를 변경 없이 축소 재사용하고 상태별 표정을 연결했다. 스크린리더에는 장식 캐릭터를 중복 낭독하지 않고 상태 텍스트로 전달한다.
- 전용 서버 `http://127.0.0.1:3327`. 새 컨텍스트 리뷰어에게 1280×900/390×844/768×900, 초기·재시작·어제4일·오늘5일 상태와 실제 제출 흐름 검토 요청.
- 구현자 확인: 단위5개·E2E2개 통과. 격리된 fixture의 완료5일/미완료4일 실제 캡처 `.bugri-hooks/previews/streak-bugri/`.

## 최초 관찰과 흐름

리뷰어는 내 연속 학습을 확인하고 바로 퀴즈를 푸는 화면으로 이해했다. 데모 로그인→number 선택→제출→1일/오늘 완료 갱신을 직접 확인했으며 다음 문제 버튼까지 확인했다(클릭은 미실행).

## 관점별 평가

| 관점 | 판단 | 근거 |
| --- | --- | --- |
| 목적·대상 | 문제 없음 | 내 프로필과 연속 학습으로 개인 화면 식별 |
| 정보 우선순위 | 문제 없음 | 1280/390에서 질문·선택·제출 첫화면 노출 |
| 핵심 행동 | 확인 범위 내 문제 없음 | 로그인→선택→제출·정답/해설·요약 갱신 직접 확인 |
| 중복·밀도 | 문제 없음 | Bugri 1개와 작은 체크/점, 클릭을 암시하는 테두리/입체감 제거 |
| 상태·피드백 | 부분 확인 | 최초/어제4일/오늘5일/재시작·날짜범위 확인, 오류는 코드만 |
| 모바일·키보드 | 문제 있음 | 390 정상, 768 재시작 문구 단어 분리. 도움말 focus/Tab으로 기록 건너뛰기 확인 |
| 사용자 상태 | 부분 확인 | 방문자 비노출/로그인 노출 직접 확인, 다른 사용자 전환은 직접 미확인 |

## 문제 목록과 처리

불꽃 제거와 기록 단순화는 사용자 피드백에 따른 변경이며 sub-agent 발견으로 기록하지 않는다.

| --- | --- | --- | --- | --- |
| UX-R0-01 | 768px 재시작에서 ‘오늘부터 다 / 시’로 단어가 분리되는 일반 사용성 문제 | 좌측 최소폭 확보, 768px 최초/재시작 단어 분리 없이 퀴즈 접근 유지 | C1: 좌측 최소240px로 조정 | R1에서 768px 최초/재시작 한줄 및 퀴즈 접근 유지 확인 |
