# FONT-IBM-PLEX-SANS-KR UX·UI 리뷰

## 대상과 증거

- 사용자 목표: 한글·영문 UI를 PC·모바일에서 읽고 퀴즈를 풀며 탐색하는 학습자(검토용 가설 페르소나).
- 확정 제약: 기본 UI 폰트만 IBM Plex Sans KR로 교체. 크기·굵기·행간·여백·색상·레이아웃·문구·기능, 코드 monospace, 로고·아이콘은 유지. 폰트 후보 재제안 금지.
- 코드 버전: 브랜치 `style/font`, 미커밋 diff(`src/app/layout.tsx`, `src/app/globals.css`). Node v22.23.3, production 서버 포트 3240.
- 리뷰어: 새 컨텍스트의 독립 UX sub-agent 1명, UI sub-agent 1명. 직접 조작은 Playwright chromium(1440×900, 390×844)이다.
- 확인 범위: `/`, `/?user=learner`, `/discover`, `/solve`, `/quizzes/authoring`, `/settings`, `/shop`. 한글 전체, 영문 일부, 다크 일부.
- 한계: 이전 폰트와 나란한 비교는 하지 못했다(stash 금지). 이전 대비 판단은 가설이다.

## 최초 관찰 요약

- UX: 홈(로그인)에서 제목·퀴즈·"답 제출"이 첫 화면에 들어오고 한영 혼용 문장의 기준선이 맞는다. 7개 화면 × 2개 viewport × ko/en에서 가로 스크롤과 잘림이 없었다.
- UI: 위계(24px/700 제목, 본문 400)·정렬·모바일 구성·다크 대비가 유지된다. 한글 unicode-range 슬라이스가 로드되어 시스템 폰트 폴백이 없었다.
