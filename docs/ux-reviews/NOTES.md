# NOTES UX·UI 리뷰

[NOTES](../tasks/NOTES.md)의 홈 빠른 메모·내 노트·메모 상세·헤더를 대상으로 한 [ux-review-loop](../../.agents/skills/ux-review-loop/SKILL.md) 기록이다. 독립 UX 리뷰어 1명과 UI 리뷰어 1명을 새 컨텍스트로 실행했고, 수정 후 같은 리뷰어를 재사용했다.

## 대상과 증거

- 사용자 가설(검토용): 업무 중 배운 개발 지식을 잊기 전에 바로 적어 두려는 현업 개발자(데모 사용자 learner). 성공 행동: 홈에서 코드 블록 포함 메모 저장 → 내 노트 → 상세에서 수정·삭제.
- 확정 제약: PRD REQ-01, 페이지 구조(빠른 메모·내 노트·상세·헤더 5요소). 임시 처리: 토스트 "메모 보기", 임시 "내 퀴즈", 퀴즈·검색·태그 없음.
- 증거: 이 워크트리 production build(격리 포트 3122)를 Playwright chromium으로 직접 조작·촬영. 직접 조작 브라우저 도구는 쓰지 않았다. viewport: 1280×800, 390×844, 360×800, 320×700. 라이트·다크, ko·en 일부.
- 미확인(양 리뷰어): 키보드 포커스 링·reduced-motion, 로딩 Skeleton, API 오류 화면, 모바일 소프트 키보드, 다크·en·360의 일부 조합, 스크린리더.
