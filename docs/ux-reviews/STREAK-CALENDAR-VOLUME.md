# STREAK-CALENDAR-VOLUME — 날짜와 학습량의 시각 구분

## 승인 범위와 구현

- 사용자 불만: 작은 검정·보라 텍스트로 학습량이 잘 드러나지 않고 날짜와 개수가 혼동된다. 검정 테두리는 싫다고 명시했다.
- 승인: 학습일 연두색 농도, 큰 완료 개수, 작은 날짜, 작은 0과 옅은 바탕, 미래 날짜만, 오늘 테두리. 후속 지적에 따라 흰 날짜 띠와 학습량 영역을 분리하고 옅은 연보라 구분선을 추가했다. 사용자 발견을 독립 리뷰어 발견으로 바꾸지 않는다.
- 날짜 띠는 모바일16/데스크톱20px, 개수 영역은24/28px로 기존40/48px 셀과 카드 높이를 유지한다. 배경은 공통 lime 토큰의 40/70/100%로 1개/2~4개/5개 이상을 구분한다. 이 기준은 시각 표시이며 일별 고유 개수·재풀이 제외 정책은 변경하지 않는다.
- 날짜별 aria-label에는 날짜·완료 상태·정확한 개수·미래 예정 의미를 유지한다. 개수 숫자와 작은 ‘개’를 분리했으므로 RTL은 해당 날짜의 접근성 이름으로 값을 확인한다.
- 구현 전 별도 UI 설계 위임. 독립 새 컨텍스트 UX·UI R0에 production3327과 390/768/1280, 1·0·3·6·2·12·4개 혼합 fixture를 제공했다. `/tmp/streak-calendar-data.cjs`는 테스트용 로컬 데이터 생성이며 제품 코드에 포함하지 않는다.
- 관련 단위15개·E2E6개 통과. 마지막 전체 verify와 실제 화면 리뷰 진행 중.


## R0와 사용자 후속 지적

- UI R0: 390/768/1280 빈·혼합 상태에서 날짜와 개수 분리, 12개 잘림 없음, 농도·0·미래 구분, 가로 넘침 없음 확인. 일반 문제 UI-01: 날짜 자식 배경이 오늘 inset ring 상단을 덮어 U자 모양으로 보인다. 날짜와 개수 전체를 연속된 보라 테두리로 감싸는 것이 해결 조건이다.
- UX R0: 혼합 28개 화면에서 날짜와 완료량 의미를 읽고 월 → 월 목록 → 연도 메뉴 → Escape → 월 복귀 및 제목 초점을 직접 확인했다. 접근성 이름과40/48px 셀 유지도 코드 확인했다.
- 혼합 fixture가 기존 활성 attempt를 삭제해 주변 퀴즈 오류를 만들었다. 제품 결함으로 분류하지 않으며 C1 검토용 fixture는 원래 완료 attempt를 보존하도록 수정했다.
- 사용자 추가 요구: 흰 날짜 띠가 이상하므로 다른 색으로 변경. 이는 사용자가 발견한 선호·시각 문제로 기록한다.

## C1

- 날짜 띠를 공통 line 토큰의 연한 라벤더색으로 바꾼다. 검정선은 추가하지 않는다.
- UI-01: 오늘 강조를 자식 배경 위의 보라색 overlay border로 바꿔 날짜와 개수 전체를 감싼다. 셀 크기·카드 높이는 유지한다.
- 동일 리뷰어 R1 및 마지막 전체 검증을 수행한다.

## R1과 종료

- UI R1: 390/768/1280에서 라벤더 날짜 영역·연두 개수 영역 구분, 12개 잘림 없음, 오늘 테두리 전체 연결을 직접 확인했다. 셀 높이40/48/48px, 가로 넘침 없음. UI-01 해결, 새 필수 문제 없음.
- UX R1: 390/1280 혼합 화면에서 작은0·미래 날짜·큰 개수와 작은‘개’ 구분, 오늘 테두리 상단까지 연결, 주변 완료 퀴즈 정상 표시를 확인했다.
- 공통 수정1회(C1/R1) 후 종료한다. 기간 탐색·키보드는 R0 직접 근거를 유지하며 R1에서는 재실행하지 않았다. 3자리 이상 수치·확대·스크린리더는 직접 미확인이다.
- 최신 캡처 `/tmp/calendar-ui-r1-{390,768,1280}.png`, `/tmp/calendar-volume-ux-r1-{390,1280}.png`, 보관 `.bugri-hooks/previews/streak-calendar/`.
- 마지막 전체 검증 결과는 TASKS에 기록한다. 초기 흰 날짜 띠 캡처는 최종 버전 근거로 사용하지 않는다.


## 사용자 후속 조정 C2

- 사용자는 오늘 테두리와 단위 없는 0을 원하지 않는다고 명시했다. C1 테두리 해결과 별개로 최종 선호를 우선한다.
- 오늘 테두리를 완전히 제거하고 날짜 띠를 primary 보라색·숫자를 흰색으로 표시한다. 다른 날짜의 라벤더 띠와 개수 영역은 유지한다.
- 0을 포함한 모든 과거 개수에 작은 ‘개’ 단위를 표시한다. 미래는 날짜만 유지한다.
- C1 전체 검증 도중 후속 변경이 도착했으므로 최종 C2 이후 다시 전체 검증한다.

## R2와 최종 확인 범위

- UI·UX R2 모두 390/1280 혼합 기록에서 오늘 보라 날짜 띠와 흰 숫자, 오늘 외곽 테두리·그림자·overlay 없음, 과거 0개·미래 날짜만 표시를 직접 확인했다.
- 혼합 수치1·0·3·6·2·12·4가 정확히 표시되고12개 잘림 없음. 셀40/48px 및 카드 높이 유지, 가로 넘침 없음. UI-01의 연속 테두리 해결 조건은 최신 사용자 선호로 대체했다.
- 공통 수정2회(C1/R1, C2/R2). R2는 기간 탐색·키보드·768px·전체 빈 기록·확대를 반복하지 않았으며 해당 기존 근거와 미확인 범위를 구분한다. 실제 스크린리더·3자리 이상 숫자는 미확인이다.
- 최종 캡처 `/tmp/calendar-ui-r2-{390,1280}.png`, `/tmp/calendar-volume-ux-r2-{390,1280}.png`, 보관 `.bugri-hooks/previews/streak-calendar/`.
