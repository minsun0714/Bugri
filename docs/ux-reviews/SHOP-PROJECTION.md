# SHOP-PROJECTION

## 사용자 피드백과 원인

- 사용자가 그림자 보완 후에도 책상이 떠 보이며 뒤 벽의 바닥선과 책상 가로선이 교차한다고 재지적했다. 앞선 접지 보완으로 해결됐다는 판단을 정정한다.
- 배경만 2점 원근, 가구·러그는 직교인 혼합 투영으로 기울기와 깊이 표현이 달랐다. 배경 있는 장면의 방/가구/러그/선택 맵을 같은 투영으로 통일하고 바닥/상판 포인터 역변환도 함께 수정한다. 저장/API 좌표는 유지한다.
- UI 사전 설계는 방 반경만 늘리는 최소안을 함께 검토했으나 기울기 불일치가 남으므로 공통 투영을 선택했다. 배경 없는 장면과 상품 썸네일은 기존 투영 유지.
- 대상 가설: 배경 상품을 데스크와 함께 확인하고 배치/구매를 판단하는 데모 학습자. 사용자 연구는 없다.

## 증거·직접 확인 범위

- 새 컨텍스트 UX/UI sub-agent가 실제 화면 먼저 관찰 후 코드 검토. production R0 3422, C1/R1 3423. PC UI1280×900 / UX1440×1000, 모바일390×844.
- 원본 사용자 이미지와 `/tmp/shop-ground-ui-desktop-preview.png`를 비교했다. `/tmp/shop-projection-*`는 모바일 방 범위 보정 전 중간 이미지이며 최종 근거와 구별한다.
- 최종 UI 캡처: `/tmp/projection-ui-r1-{moon,garden}-{1280,390}-{default,rotate,reset}.png`.
- UX R0: `/tmp/proj-ux-room.png`, `/tmp/proj-ux-{pc,mobile}-{selected,rotate}.png`, `/tmp/proj-ux-nobg-{pc,mobile}-{selected,rotate}.png`.

최초 관찰: 상품명·방이 중심이며 초기화·구매·닫기가 분리돼 목적과 다음 행동이 명료하다.

| 관점          | 판단·근거                                                                                |
| ------------- | ---------------------------------------------------------------------------------------- |
| 목적·우선순위 | 상품명·방·가격·구매가 같은 모달에 표시.                                                  |
| 핵심 흐름     | 달빛 구매→장착→키보드 미리보기→선택/이동/높이/회전→축소→닫기/재열기 직접 확인.           |
| 밀도·중복     | 새 설명/경유 없이 기존 조작 유지.                                                        |
| 상태·피드백   | 가로 이동은 높이, 세로 이동은 깊이 유지. 재열기 시 임시 좌표 복원. 선택 테두리 정합.     |

| 사용자 상태   | 데모 학습자·배경 유/무 직접 확인. 방문자/타인 공개 조회는 독립 리뷰 미확인.              |

UX 코드 독립 검토에서 평면 역산·깊이 고정 역산·상판 드롭 공통투영에 구체 결함 없음. 실제 터치 제스처, 스냅 전체 각도/극한높이 조합은 미확인. R0 필수 UX 문제0개.

### UI R1

- 같은 리뷰어가 PC1280×900/mobile390×844 두 테마 기본→회전→초기화 직접 확인.
- PC 러그 하단 약23px, 창문 상단 약37px 여백. 전체 러그 표시 및 초기화 복원. 모바일 정면 가까운 회전에서 양옆 벽 표시.
- 벽선·상판 교차 재발 및 새 필수 시각 결함 없음. 사용자 확대에 따른 경계 잘림은 별도 결함으로 판단하지 않았다.
- R1 확대·구매·정밀 역좌표 드래그/키보드는 UI 관점 미확인. UX/자동화 근거와 구별한다.

## 회차·검증

- UI 수정 C1/R1 1회. 사용자 지적은 에이전트가 최초 발견한 문제로 기록하지 않는다.
- Node v22.23.3, 공통투영/역변환 단위6개 통과.
- 관련 최초 E2E8개 중7개 통과/모바일 room-zoom1개 실패(정면 양벽 모서리 프레임 밖). 방 반경 보정 후 동일 검사1개 실패. C1 기본 fit 여유와 독립 반경으로 보완했다. 검증 기대/시간제한을 낮추지 않았다.
- 최종 관련 신규 기본벽선/야간키보드상판 스냅2개·기존room-zoom2개 모두 통과. `/tmp/projection-related3.log`. 배경있는 방과 가구의 동일 픽셀 좌표·역변환, 벽선이 상판 뒤에 있는 기본 구도·배경있는 방의 실제 상판 스냅을 검증한다.
- 마지막 전체검증 `PLAYWRIGHT_PORT=3420 npm run verify -- -- --workers=1` 실행. 순차 실행은 기존 병렬부하 timeout 이력을 고려하며 범위는 전체 유지한다.

- PC 회전·축소 후 상판 직접 드롭도 Y1.55와 선택 테두리 정합 확인. 모바일 스냅 성공을 독립 리뷰가 직접 확인했다고 확대해 주장하지 않으며 자동화2개 근거와 구별한다.
