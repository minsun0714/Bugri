# SHOP-DEMO-STRIP

## 범위·설계

- 사용자 요청: 상점 위 `데모: 학습자 · 사용자 전환` 줄 삭제.
- `/shop`에서만 해당 행 전체를 제거하고 내 프로필 메뉴의 마이페이지 다음·데모 나가기 앞에 `데모 사용자 전환` 버튼을 둔다. 다른 페이지의 기존 행과 방문자 데모 선택은 유지한다.
- 사전 UI 설계: 기존 메뉴 항목 스타일 재사용, 설명/구분선 추가 없음. 메뉴 항목이 사라져도 모달 취소 초점을 복원할 수 있도록 프로필 버튼에 먼저 초점을 놓고 모달을 연다.
- 사용자 가설: 상품을 탐색하며 필요할 때 데모 사용자를 전환하는 학습자. 실제 인증은 아니다.

## 검증

- Node v22.23.3. 메뉴 전환과 지속되는 트리거 초점 단위 테스트를 먼저 작성해 미구현 실패1개 확인 후 구현. 관련 navigation 단위8개 통과.
- 상점 E2E8개 통과: PC1280/mobile390에서 데모 행 미표시, 프로필 메뉴→전환 모달→Escape 초점 복귀, 친구 선택·잔액/보유 분리·새로고침/뒤로가기/홈 이동 확인. `/tmp/shop-strip-related.log`.
- 최종 `PLAYWRIGHT_PORT=3424 npm run verify -- -- --workers=2` 실행. 전체 검사 범위 유지, 기본4worker 대신2로 실행.
