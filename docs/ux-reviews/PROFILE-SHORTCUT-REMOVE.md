# PROFILE-SHORTCUT-REMOVE

## 범위·증거

사용자 확정 요청: 소개 아래 ‘공개 퀴즈 N개 보기 ↓’를 개수와 관계없이 제거. 데스크·아래 퀴즈 목록·전체 보기·편집 위치 유지. 새 디자인 없이 링크와 전용 prop/앵커/포커스 처리를 삭제하는 작은 변경이다.

7b83c60 이후 미커밋 변경을 격리 production 서버 127.0.0.1:3158에서 확인했다. 새 컨텍스트 shortcut_remove_ux와 shortcut_remove_ui가 실제 화면을 먼저 보고 코드를 확인했다. 테스트 결과를 독립 판단 근거로 사용하지 않았다.

## UX R0

최초 이해: 공개 ID로 사용자 프로필을 식별하고 데스크 아래에서 퀴즈를 고른다. PC1280×900·모바일390×844 게스트/본인, author2개·learner0개 확인.

| 관점 | 관찰 |
| --- | --- |
| 목적·대상 | 공개 ID와 경로로 식별 |
| 위계·첫 화면 | 데스크 아래 퀴즈 제목·전체 보기가 첫 화면에 나타남 |
| 행동 | 모바일 전체 보기 포커스+Enter로 개발자 목록 이동, 퀴즈 제목 클릭으로 풀이 이동 직접 확인 |
| 밀도 | 상단 바로가기·빈 컨트롤 없음, 아래 목록 유지 |
| 상태 | 0개·2개 모두 바로가기 없음, 0개 빈 상태 표시 |
| 모바일·키보드 | 한 열 목록, 전체 보기 키보드 실행 가능 |
| 사용자 상태 | 게스트 구독하기·본인 편집의 기존 위치 유지 |

필수 문제0개. 소개가 채워진 상태·로그인 타인·전체 Tab 순서·스크린리더 미확인. 0개 전체보기 클릭 후 본문 수집은 전환 중 복수 main 때문에 실패했으므로 해당 도착 화면은 확인 완료로 기록하지 않는다. 캡처 `/tmp/shortcut-ux-{pc,owner-pc,mobile,empty}.png`.

| 관점 | 관찰 |
| --- | --- |
| 위계 | ID→데스크→최신 퀴즈 순서 유지, 상단 바로가기 없음 |
| 간격·정렬 | 삭제 자리에 빈 행/컨테이너 없음, 편집 우측 정렬 유지 |
| 타이포·색·일관성 | 기존 제목·카드·전체 보기와 행동 색 유지, 고립된 장식 없음 |
| 비례·모바일 | 단일 열 목록과 제목/전체보기 행 유지, 빈 상태·인접 영역 잘림 없음 |

필수·선택 문제0개. 소개가 채워진 상태·편집 중·모바일 learner 소유자·키보드는 UI 리뷰에서 미확인. 코드에서도 quizNavigation과 빈 래퍼 제거를 확인했다.
