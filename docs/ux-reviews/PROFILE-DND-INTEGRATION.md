# PROFILE-DND-INTEGRATION — 다크 테마 통합 리뷰

## 대상과 증거

- 코드 `beb2b70`, upstream `12680f5`, Node v22.23.3. 본인 프로필에서 우선순위를 편집하고 방문자는 공개 퀴즈로 이동하는 흐름을 검토했다.
- 확정 제약은 소개 상단 고정, 간결한 세 행 모달, 저장/취소, 헤더 관리 그룹, 중립색 전체 보기다. 통합 회귀만 검토했다.
- 독립 UX/UI 리뷰어가 production 서버 3136을 Node Playwright로 직접 조작했다. UX는 다크 390/320×900, UI는 라이트/다크 × 1280/390/320×900 × author/learner를 확인했다.

## R0 UX

첫 화면의 공개 ID로 주인을 식별하고 관리 그룹에서 편집을 발견할 수 있다. 모달은 세 섹션과 저장/취소만 보여준다.

| 관점             | 관찰 근거                                                                                                |
| ---------------- | -------------------------------------------------------------------------------------------------------- |
| 목적·대상        | ID와 관리 버튼 문구가 다크에서도 읽힌다.                                                                 |
| 우선순위·첫 화면 | 사용자 정보는 고정되고 모달에는 편집할 세 섹션만 표시된다.                                               |
| 핵심 행동        | 두 모바일 폭에서 진입→손잡이 ArrowDown→저장 후 본문 순서 변경을 직접 확인했다.                           |
| 밀도·중복        | 별도 편집 툴바가 없고 빈 퀴즈 패널은 제목·전체 보기·한 줄 안내로 유지된다.                               |
| 상태·피드백      | 저장 토스트와 재편집 후 취소 시 저장 순서 보존을 확인했다.                                               |
| 모바일·키보드    | 가로 넘침 없음, 첫 손잡이와 이동 후 포커스 표시, 저장/취소/Escape 후 트리거 복귀를 확인했다.             |
| 방문자·본인      | 게스트 전환 시 편집 버튼이 숨겨지고 저장 순서는 유지된다. author 게스트 전체 보기 Enter로 목록 이동했다. |

## R0 UI

ID와 관리 그룹, 콘텐츠 패널과 모달의 역할이 구분된다. 320px에서도 두 편집 버튼이 한 줄을 유지한다. 화살표·연필이 구별되고, 퀴즈 패널 제목·개수·중립 전체 보기·보조 태그는 다크에서도 읽힌다. 카드와 패널은 테두리·간격으로 경계가 구분된다. learner 빈 상태는 두 테마에서 작은 높이를 유지한다.

라이트/다크의 세 폭·두 사용자에서 모달 열기→퀴즈 위로 이동→Tab→저장을 직접 수행했다. 320px의 퀴즈 이름 두 줄은 이동 버튼을 침범하지 않고 세 행과 저장/취소가 viewport에 들어온다. 포커스 링, 비활성 화살표, 성공 토스트를 구분할 수 있다. 별도 신규 브라우저 다크 320px 방문자 화면에서 편집 버튼이 없는 상태도 확인했다.

## 문제 목록·종료

필수 문제 0개, 수정 0회로 종료한다. 방 캔버스의 밝은 표면은 upstream의 사용자 방 색 보존 요구로 유지한다. 정적 통합 리뷰에서도 upstream 다크 토큰과 양쪽 문서 기록 보존을 확인했다.

증거: `/tmp/integrated-ux-{320|390}.png`, `/tmp/integrated-ux-modal-{320|390}.png`, `/tmp/review-{dark|light}-{1280|390|320}-{author|learner}.png`와 `-modal.png`, `/tmp/review-dark-320-visitor.png`.

한계: 실제 모바일 장치·스크린리더·다른 브라우저 미확인. UI 색 대비 수치·전체 키보드 순회·드래그·퀴즈 상세 이동은 미확인이다. UX 저장 실패 주입은 이번 통합 리뷰에서 반복하지 않았다. 기존 리뷰/자동 회귀 결과와 직접 화면 관찰은 별도 근거다.
