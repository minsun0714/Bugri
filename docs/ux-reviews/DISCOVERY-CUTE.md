# DISCOVERY-CUTE — 홈 컨셉과 탐색 버그리

## 대상과 확정 요청

- 사용자 요청: 개발자 탐색을 홈과 비슷한 컨셉으로 깜찍하게 변경하고, 버그리는 이 페이지의 목적에 맞게 탐색하는 모습으로 표시한다. 기존 검색·구독·오류·키보드 흐름을 보존한다.
- 최신dev13fcd7c의 URL 기반 명시적 데모 사용자 선택·방문자 홈·공개 프로필을 보존한다. 실제 인증은 추가하지 않는다.
- 홈 비교 설계는 별도 UI 에이전트가 수행했다. 최신 홈의24px 제목·흰 rounded3xl 패널·라벤더선·보라/연두 토큰을 재사용했다. 공통Avatar와 로컬SVG/CSS를 결합한 탐색 전용 버그리, 검색 패널, PC3열/중간2열/mobile1열, 동일 하단 행의 퀴즈수/구독을 적용했다.
- 버그리는 몸을 기울이고 돋보기를 쥔 손·확대눈으로 탐색 행동을 표현한다. 홈/공통 Bugri 표현은 수정하지 않았다. 불필요한 설명카피와 애니메이션은 추가하지 않았다.

## 직접 증거

- 독립 새 컨텍스트 UX/UI R0. 초기동일워크트리3100, 사용자 dev 재기동 후3001. PC1440×900(UX1280×900 포함),375/390 및320×740/900 Chromium 직접 조작.
- UX: 검색→guest 데모 선택→원래조건 보존/자동구독없음→명시적 구독→내 구독3종/해제/초점, 프로필·퀴즈·홈 이동.
- UI: 최신 홈과 탐색 guest/friend/learner, 빈검색·101자 오류·구독관리의 PC/mobile 실제 비교.
- 캡처: `/tmp/cute-new-pc.png`, `/tmp/cute-new-mobile.png`(초기시안), `/tmp/ui-r1-{guest,member,empty}-{1440,375,320}.png`(최종캐릭터 포함), `/tmp/cute-ux-r1-320.png`, `/tmp/cute-ux-r1-empty.png`. 로컬 세션 파일이며 초기시안은 최종보다 큰제목/그림자와 이전캐릭터를 포함할 수 있다.

## 회차와 한계

- R0: UX 필수문제0개. UI 선택개선2개. 독립코드리뷰 취소초점1개.
- C1/R1: 두UI개선·취소콜백 및 사용자요청 탐색캐릭터 반영. 두리뷰어가 실제화면/흐름 재검증, 새필수문제0개. 수정1회로 종료.
- 독립 UX는 오류주입·전체키보드·스크린리더·대량다중페이지를 직접검증하지 않았다. UI는 자동색대비 수치/네트워크실패·실기기Safari 미확인. 저장실패/손상복구는 메인E2E로 확인했다. 기존헤더 선택완료초점의 선택개선1개 보류.
- 외부병합으로 중간검증 버전이 바뀐 이력과 최종타입/단위/E2E/전체검증 결과는 TASKS에 기록한다.
