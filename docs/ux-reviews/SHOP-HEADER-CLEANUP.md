## 대상과 증거

- 승인 범위: `/shop` 본문 홈 링크·더미 사용자 행 제거. 공통 헤더 URL 사용자 전환에 상점 잔액·보유 상품 연결. 데스크·독립 전시는 제외.
- 사용자 가설: 상품을 구매하고 다른 데모 사용자로 전환하거나 홈으로 돌아가려는 개발자.
- 최신 미커밋 `shop-app.tsx`, production `http://127.0.0.1:3417`, PC 1280×900/mobile 390×844. UX/UI 별도 sub-agent가 직접 Playwright로 화면을 캡처하고 관찰했다. UX는 동작과 코드도 독립 검토했다.
- UX 캡처: `/tmp/shop-header-ux-pc.png`, `/tmp/shop-header-ux-mobile.png`.
- UI 캡처: `/tmp/shop-header-ui-{pc,mobile}-{learner,guest}.png`.
